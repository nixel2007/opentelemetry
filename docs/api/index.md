# Публичный интерфейс библиотеки `opentelemetry`

* [ОтелПостроительРесурса](./Ядро/ОтелПостроительРесурса.md) — построитель ресурса (fluent API)

* [ОтелДетекторРесурсаПроцесса](./Ядро/ОтелДетекторРесурсаПроцесса.md) — детектор ресурса процесса: идентификатор процесса
* [ОтелДетекторРесурсаПроцессора](./Ядро/ОтелДетекторРесурсаПроцессора.md) — детектор ресурса процессора: модель и архитектура
* [ОтелОбластьИнструментирования](./Ядро/ОтелОбластьИнструментирования.md) — InstrumentationScope: описание библиотеки инструментации
* [ОтелКонтекст](./Ядро/ОтелКонтекст.md) — модуль управления текущим контекстом выполнения
* [ОтелКлючКонтекста](./Ядро/ОтелКлючКонтекста.md) — ключ для хранения значений в контексте
* [ОтелТокенКонтекста](./Ядро/ОтелТокенКонтекста.md) — токен, возвращаемый при присоединении контекста
* [ОтелBaggage](./Ядро/ОтелBaggage.md) — передача контекстных данных между сервисами (W3C Baggage)
* [ОтелПостроительBaggage](./Ядро/ОтелПостроительBaggage.md) — построитель Baggage (fluent API)
* [ОтелСемантическиеСоглашения](./Ядро/ОтелСемантическиеСоглашения.md) — модуль констант семантических соглашений: имена атрибутов и метрик db.*, server.*, error.type, code.*
* [ОтелРезультатЭкспорта](./Ядро/ОтелРезультатЭкспорта.md) — результат операции экспорта или принудительной выгрузки
* [ОтелРезультатыЭкспорта](./Ядро/ОтелРезультатыЭкспорта.md) — модуль создания результатов экспорта: успех, ошибка, таймаут, сведение нескольких результатов
* [ОтелРезультатЗакрытия](./Ядро/ОтелРезультатЗакрытия.md) — результат операции закрытия / принудительной выгрузки
* [ОтелРезультатыЗакрытия](./Ядро/ОтелРезультатыЗакрытия.md) — модуль создания результатов закрытия: успех, ошибка, таймаут
* [ОтелУтилиты](./Ядро/ОтелУтилиты.md) — время в формате OpenTelemetry (строка наносекунд), часы SDK и генератор идентификаторов
