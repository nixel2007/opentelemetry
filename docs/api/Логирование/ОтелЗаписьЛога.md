# ОтелЗаписьЛога

Запись лога (LogRecord) — объект, содержащий все поля одной записи лога.

## Описание

`ОтелЗаписьЛога` реализует спецификацию OpenTelemetry LogRecord / ReadWriteLogRecord.
Содержит: тело, серьезность, атрибуты, время, имя события, контекст трассировки, ресурс и scope.

После вызова `Логгер.Записать()` запись фиксируется (`Зафиксировать()`) и становится
неизменяемой — все сеттеры превращаются в no-op.

Уважает лимиты атрибутов из [ОтелЛимитыЗаписейЛога](./ОтелЛимитыЗаписейЛога.md):
атрибуты сверх лимита отбрасываются, длинные строковые значения усекаются.

## Конструктор

| Параметр | Тип | По умолчанию | Описание |
|---|---|---|---|
| `ЛимитыЗаписейЛога` | `ОтелЛимитыЗаписейЛога` | `Неопределено` | Лимиты записей лога (иначе 128 атрибутов, без ограничения длины) |

## Методы — Геттеры

### Время

Возвращает время записи лога в наносекундах Unix epoch.

**Возвращает:** `Строка`

---

### ВремяНаблюдения

Возвращает время наблюдения записи лога в наносекундах Unix epoch.

**Возвращает:** `Строка`

---

### НомерСерьезности

Возвращает номер серьезности (SeverityNumber).

**Возвращает:** `Число` — 0 (`SEVERITY_NUMBER_UNSPECIFIED`), если серьезность не задана

---

### ТекстСерьезности

Возвращает текст серьезности (SeverityText).

**Возвращает:** `Строка` — пустая строка, если серьезность не задана

---

### Тело

Возвращает тело записи лога.

**Возвращает:** `Строка`

---

### Атрибуты

Возвращает копию атрибутов записи лога. Изменение копии не меняет запись: атрибуты записываются
через `УстановитьАтрибут`, который применяет лимиты [ОтелЛимитыЗаписейЛога](./ОтелЛимитыЗаписейЛога.md).

**Возвращает:** `ОтелАтрибуты`

---

### ИдТрассировки

**Возвращает:** `Строка`

---

### ИдСпана

**Возвращает:** `Строка`

---

### ФлагиТрассировки

**Возвращает:** `Число`

---

### Ресурс

**Возвращает:** `ОтелРесурс`

### ОбластьИнструментирования

Возвращает область инструментирования (InstrumentationScope).

---

### КоличествоОтброшенныхАтрибутов

**Возвращает:** `Число`

### ИмяСобытия

**Возвращает:** `Строка`

## Методы — Сеттеры (fluent API)

Все сеттеры возвращают `ОтелЗаписьЛога` (`ЭтотОбъект`) для цепочки вызовов.
После `Зафиксировать()` становятся no-op.

### УстановитьСерьезность

Устанавливает серьезность по номеру из `ОтелСтепеньСерьезности`. Если текст серьезности не задан явно
через `УстановитьТекстСерьезности`, в `ТекстСерьезности` подставляется короткое имя номера.

| Параметр | Тип | По умолчанию | Описание |
|---|---|---|---|
| `Значение` | `Число` | — | Номер серьезности (см. [ОтелСтепеньСерьезности](./ОтелСтепеньСерьезности.md)) |

---

### УстановитьТекстСерьезности

Устанавливает произвольный текст серьезности независимо от номера. Явно заданный текст не заменяется
последующими вызовами `УстановитьСерьезность`.

| Параметр | Тип | По умолчанию | Описание |
|---|---|---|---|
| `Значение` | `Строка` | — | Текст серьезности |

---

### УстановитьТело

Устанавливает тело записи. Принимает строку, число, булево, массив или соответствие (AnyValue).

| Параметр | Тип | По умолчанию | Описание |
|---|---|---|---|
| `Значение` | `Произвольный` | — | Содержимое лога |

---

### УстановитьАтрибут

Устанавливает атрибут записи лога. Уважает лимиты: атрибуты сверх лимита отбрасываются, строки длиннее лимита усекаются.

| Параметр | Тип | По умолчанию | Описание |
|---|---|---|---|
| `Ключ` | `Строка` | — | Имя атрибута |
| `Значение` | `Произвольный` | — | Значение атрибута |

---

### УдалитьАтрибут

| Параметр | Тип | По умолчанию | Описание |

---

### УстановитьИсключение

Устанавливает информацию об исключении. SDK автоматически извлечёт атрибуты
`exception.type`, `exception.message`, `exception.stacktrace`. Атрибут, уже заданный в записи,
SDK не перезаписывает.

`exception.type` — машинный код ошибки библиотеки [errors](https://github.com/Stivo182/oscript-errors)
(`ДиагностикаОшибок.КодОшибки`, в том числе через обертки `ФабрикаОшибок.Обернуть` и
`ФабрикаОшибок.ОбернутьКонтекстом`). У ошибки без кода атрибут не заполняется: по семантическим
соглашениям он обязателен, только если нет `exception.message`.

| Параметр | Тип | По умолчанию | Описание |
|---|---|---|---|
| `Значение` | `ИнформацияОбОшибке` | — | Информация об исключении |

---

### Зафиксировать

Фиксирует запись лога, делая её неизменяемой. Автоматически вызывается в `Логгер.Записать()`.

## Внутренние методы

Экспортированы только для вызова из других модулей SDK (в OneScript нет внутренней видимости),
приложению вызывать их не нужно:

- `УстановитьРесурс` — устанавливает ресурс записи: логгер в `Записать` передаёт ресурс провайдера;
- `УстановитьОбластьИнструментирования` — устанавливает область инструментирования записи: логгер
  в `Записать` передаёт свою область.

## Пример

```bsl
Запись = Логгер.СоздатьЗаписьЛога();
Запись
    .УстановитьСерьезность(ОтелСтепеньСерьезности.Error())
    .УстановитьТело("Критическая ошибка обработки заказа")
    .УстановитьАтрибут("order.id", "12345")
    .УстановитьАтрибут("user.id", "42")
    .УстановитьИмяСобытия("order.failed");
Логгер.Записать(Запись);

// С исключением
Попытка
    ОбработатьЗаказ();
Исключение
    Запись = Логгер.СоздатьЗаписьЛога();
    Запись
        .УстановитьСерьезность(ОтелСтепеньСерьезности.Error())
        .УстановитьТело("Ошибка обработки заказа")
        .УстановитьИсключение(ИнформацияОбОшибке());
    Логгер.Записать(Запись);
КонецПопытки;
```
