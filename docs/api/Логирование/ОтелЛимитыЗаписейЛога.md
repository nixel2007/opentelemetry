# ОтелЛимитыЗаписейЛога

Лимиты записей лога (LogLimits) — настройки ограничений атрибутов.

## Описание

`ОтелЛимитыЗаписейЛога` задаёт ограничения на количество атрибутов и длину их строковых значений
в [ОтелЗаписьЛога](./ОтелЗаписьЛога.md). Используется при создании провайдера через
[ОтелПостроительПровайдераЛогирования](./ОтелПостроительПровайдераЛогирования.md).

Аналог Java SDK: `io.opentelemetry.sdk.logs.LogLimits`.

По умолчанию: максимум 128 атрибутов, без ограничения длины строковых значений, глубина значения
не больше 64. Лимит длины действует и на строки внутри массивов, вложенный массив глубже лимита
заменяется пустым значением.

## Методы

### МаксАтрибутов

Возвращает максимальное количество атрибутов записи лога.

**Возвращает:** `Число`

---

### МаксДлинаЗначенияАтрибута

Возвращает максимальную длину значения строкового атрибута.

**Возвращает:** `Число`, `Неопределено` — лимит; `Неопределено` (по умолчанию) — без ограничения, `0` — строки усекаются до пустых

---

### МаксГлубинаЗначенияАтрибута

Возвращает максимальную глубину значения атрибута. Глубина верхнего значения — 1.

**Возвращает:** `Число` — по умолчанию `64`

---

### УстановитьМаксАтрибутов

Устанавливает максимальное количество атрибутов записи лога.

| Параметр | Тип | По умолчанию | Описание |
|---|---|---|---|
| `Значение` | `Число` | — | Максимальное количество атрибутов |

**Возвращает:** `ОтелЛимитыЗаписейЛога` — `ЭтотОбъект` для цепочки вызовов

---

### УстановитьМаксДлинаЗначенияАтрибута

Устанавливает максимальную длину значения строкового атрибута.

| Параметр | Тип | По умолчанию | Описание |
|---|---|---|---|
| `Значение` | `Число`, `Неопределено` | — | Максимальная длина; `Неопределено` — без ограничения, `0` — нулевой лимит |

**Возвращает:** `ОтелЛимитыЗаписейЛога` — `ЭтотОбъект` для цепочки вызовов

---

### УстановитьМаксГлубинаЗначенияАтрибута

Устанавливает максимальную глубину значения атрибута.

| Параметр | Тип | По умолчанию | Описание |
|---|---|---|---|
| `Значение` | `Число` | — | Максимальная глубина (глубина верхнего значения — 1) |

**Возвращает:** `ОтелЛимитыЗаписейЛога` — `ЭтотОбъект` для цепочки вызовов

## Пример

```bsl
Лимиты = Новый ОтелЛимитыЗаписейЛога()
    .УстановитьМаксАтрибутов(256)
    .УстановитьМаксДлинаЗначенияАтрибута(2048);

Провайдер = Новый ОтелПостроительПровайдераЛогирования()
    .УстановитьРесурс(Ресурс)
    .УстановитьЛимитыЗаписейЛога(Лимиты)
    .Построить();
```
