# ОтелКонсольныйТранспорт

Консольный транспорт экспортеров OTLP — экспортер `console` файла конфигурации.

## Описание

Реализует тот же интерфейс `Отправить(Путь, Данные, ТаймаутМс)`, что и [ОтелHttpТранспорт](./ОтелHttpТранспорт.md)
и [ОтелGrpcТранспорт](./ОтелGrpcТранспорт.md). Вместо отправки по сети выводит данные в стандартный
вывод (`Сообщить`): каждая отправка — одна строка OTLP JSON, например `{"resourceSpans":[...]}`.
С [ОтелЭкспортерСпанов](./ОтелЭкспортерСпанов.md), [ОтелЭкспортерЛогов](./ОтелЭкспортерЛогов.md) и
[ОтелЭкспортерМетрик](./ОтелЭкспортерМетрик.md) даёт консольные экспортеры спанов, записей логов и
метрик — для отладки и локальной разработки. Формат вывода — OTLP JSON, как в теле запроса
`http/json`; путь сигнала в вывод не попадает.

Транспорт потокобезопасен: строки разных отправок не перемешиваются.

## Конструктор

Конструктор без параметров.

```bsl
Новый ОтелКонсольныйТранспорт()
```

## Методы

### Отправить

Выводит данные одной строкой OTLP JSON. Если транспорт закрыт, ничего не выводит и возвращает
`Ложь`. Вывод не ждёт сети, поэтому срок отправки не используется.

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `Путь` | Строка | — | Путь сигнала, например `"/v1/traces"` |
| `Данные` | Соответствие | — | Данные в формате OTLP JSON |
| `ТаймаутМс` | Число | `0` | Срок отправки в миллисекундах, `0` — без ограничения |

**Возвращает:** `Булево` — `Истина`, если транспорт не закрыт и данные выведены

### Закрыть

Завершает работу транспорта. После вызова метод `Отправить()` ничего не выводит и возвращает `Ложь`.

## Пример

```bsl
#Использовать opentelemetry

Экспортер = Новый ОтелЭкспортерСпанов(Новый ОтелКонсольныйТранспорт());
Провайдер = Новый ОтелПостроительПровайдераТрассировки()
    .ДобавитьПроцессор(Новый ОтелПростойПроцессорСпанов(Экспортер))
    .Построить();

Провайдер.ПолучитьТрассировщик("пример").НачатьСпан("операция").Завершить();
// В стандартный вывод: {"resourceSpans":[{"resource":...,"scopeSpans":[...]}]}

Провайдер.Закрыть();
```
