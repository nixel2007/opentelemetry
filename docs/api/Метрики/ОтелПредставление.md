# ОтелПредставление

Представление (View) — конфигурация агрегации и фильтрации для инструмента метрик.

## Описание

`ОтелПредставление` позволяет переопределить имя, описание, атрибуты, границы гистограммы
и тип агрегации для отдельных инструментов метрик — синхронных и асинхронных.

Регистрируется в [ОтелПостроительПровайдераМетрик](./ОтелПостроительПровайдераМетрик.md).

Правила применения:

- каждый View, выбравший инструмент, даёт отдельный поток метрики у каждого читателя (режим
  `independent`); в режиме `composable` View с одним именем потока объединяются
  (см. `ОтелПровайдерМетрик.УстановитьРежимСопоставленияПредставлений`);
- настройки View приоритетнее advisory-параметров инструмента: если View задаёт
  `РазрешенныеКлючиАтрибутов` или `ИсключенныеКлючиАтрибутов`, advisory `КлючиАтрибутов` не
  применяется; `ГраницыГистограммы` View приоритетнее advisory-границ, а агрегация
  `explicit_bucket_histogram` из View advisory-границы не использует;
- аспекты, которые View не задал, берутся у читателя: агрегация и лимит мощности по умолчанию
  для вида инструмента;
- View с семантической ошибкой (агрегация, несовместимая с видом инструмента, например
  гистограмма для асинхронного инструмента, или неизвестная агрегация) игнорируется целиком —
  как если бы его не было, в лог пишется предупреждение;
- если View даёт двум потокам одного читателя одно имя (например, переименовывает инструмент в
  имя существующего), оба потока экспортируются, в лог пишется предупреждение о конфликте
  идентичности метрик;
- View, зарегистрированный после создания инструмента, применяется к измерениям, записанным
  после регистрации.

> **Exemplars и отфильтрованные атрибуты.** Атрибуты, исключённые представлением
> (`РазрешенныеКлючиАтрибутов`, `ИсключенныеКлючиАтрибутов`), всё равно могут экспортироваться
> в exemplars как `filteredAttributes`. Чтобы они не уходили в exemplars, выключите exemplars
> фильтром `ОтелФильтрЭкземпляров.ВсегдаВыключен()` (`OTEL_METRICS_EXEMPLAR_FILTER=always_off`)
> или передайте `Новый ОтелФабрикаNoopРезервуаров()` в параметр `РезервуарЭкземпляров`.

## Конструктор

Все параметры опциональны.

| Параметр | Тип | По умолчанию | Описание |
|---|---|---|---|
| `НовоеИмя` | `Строка` | `Неопределено` | Переопределённое имя инструмента |
| `НовоеОписание` | `Строка` | `Неопределено` | Переопределённое описание |
| `РазрешенныеКлючиАтрибутов` | `Массив` | `Неопределено` | Список разрешённых ключей атрибутов |
| `ГраницыГистограммы` | `Массив` | `Неопределено` | Явные границы бакетов гистограммы |
| `Агрегация` | [`ОтелАгрегация`](./ОтелАгрегация.md) | `Неопределено` | Стратегия агрегации |
| `ИсключенныеКлючиАтрибутов` | `Массив` | `Неопределено` | Список исключённых ключей атрибутов |
| `РезервуарЭкземпляров` | Фабрика резервуаров | `Неопределено` | Фабрика резервуаров exemplars потока — объект с методом `СоздатьРезервуар()`: резервуар создаётся на каждую серию. `Новый ОтелФабрикаNoopРезервуаров()` отключает exemplars. Объект без `СоздатьРезервуар()` отклоняется с ошибкой в логе, используется резервуар по умолчанию |
| `ЛимитМощностиАгрегации` | `Число` | `Неопределено` | Лимит cardinality |

## Методы

### НовоеИмя

**Возвращает:** `Строка`, `Неопределено`

---

### НовоеОписание

**Возвращает:** `Строка`, `Неопределено`

---

### РазрешенныеКлючиАтрибутов

**Возвращает:** `Массив`, `Неопределено`

---

### ИсключенныеКлючиАтрибутов

**Возвращает:** `Массив`, `Неопределено`

---

### ГраницыГистограммы

**Возвращает:** `Массив`, `Неопределено`

---

### Агрегация

**Возвращает:** [`ОтелАгрегация`](./ОтелАгрегация.md), `Неопределено`

---

### РезервуарЭкземпляров

**Возвращает:** фабрика резервуаров или `Неопределено`

---

### ЛимитМощностиАгрегации

**Возвращает:** `Число`, `Неопределено`

## Пример

```bsl
// Переименовать инструмент и задать границы гистограммы
Границы = Новый Массив();
Границы.Добавить(0.005);
Границы.Добавить(0.01);
Границы.Добавить(0.025);
Границы.Добавить(0.05);
Границы.Добавить(0.1);
Границы.Добавить(0.25);
Границы.Добавить(0.5);
Границы.Добавить(1);

Представление = Новый ОтелПредставление(
    "http_request_duration_seconds",    // НовоеИмя
    Неопределено,                       // НовоеОписание
    Неопределено,                       // РазрешенныеКлючиАтрибутов
    Границы);                           // ГраницыГистограммы

Селектор = Новый ОтелСелекторИнструментов("http.request.duration");
Построитель = Новый ОтелПостроительПровайдераМетрик();
Построитель.ЗарегистрироватьПредставление(Селектор, Представление);
```
