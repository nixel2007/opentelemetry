# ОтелМетр

Метр (Meter) — фабрика метрических инструментов.

## Описание

`ОтелМетр` создаёт и возвращает инструменты для записи метрик: счётчики, датчики, гистограммы
и наблюдаемые инструменты. Инструменты кэшируются по нормализованному имени.

При повторной регистрации с тем же именем (без учёта регистра), тем же видом и той же единицей
измерения возвращается уже существующий инструмент; конфликт описания или advisory-параметров
логируется как предупреждение.

Если при повторной регистрации отличается вид инструмента или единица измерения, возвращается
отдельный инструмент запрошенного вида с именем первой регистрации. Его данные экспортируются
отдельной метрикой, в лог пишется предупреждение. Повторный вызов с теми же параметрами
возвращает этот же инструмент.

Все публичные методы потокобезопасны.

Имя инструмента должно соответствовать паттерну `[A-Za-z][A-Za-z0-9_./-]{0,254}`.

## Методы

### СоздатьСчетчик

Создаёт монотонный счётчик ([ОтелСчетчик](./ОтелСчетчик.md)) — принимает только неотрицательные значения.

| Параметр | Тип | По умолчанию | Описание |
|---|---|---|---|
| `Имя` | `Строка` | — | Имя счётчика |
| `Описание` | `Строка` | `""` | Описание |
| `ЕдиницаИзмерения` | `Строка` | `""` | Единица измерения |
| `Совет` | `Структура`, `Неопределено` | `Неопределено` | Advisory-параметры |

**Возвращает:** `ОтелСчетчик`

### ЗарегистрироватьОбратныйВызов

Регистрирует один callback для нескольких наблюдаемых инструментов этого метра (multi-instrument
callback). Регистрация с синхронным инструментом или инструментом другого метра отклоняется с
предупреждением в логе. Наблюдения одного вызова callback получают одно время для всех инструментов.

| Параметр | Тип | По умолчанию | Описание |
|---|---|---|---|
| `Callback` | `Действие` | — | Вызывается с `Соответствие` (имя инструмента → `ОтелНаблюдениеМетрики`), вторым аргументом — `Состояние`, если оно задано |
| `НовыеИнструменты` | `Массив` | — | Наблюдаемые (асинхронные) инструменты этого метра |
| `Состояние` | Произвольный | `Неопределено` | Состояние регистрации, передаётся в каждый вызов |

**Возвращает:** [ОтелРегистрацияНаблюдателя](./ОтелРегистрацияНаблюдателя.md) — токен регистрации: `Закрыть()` отменяет её. У отклонённой регистрации `Закрыть()` ничего не делает.

## Требования к callback

Для callback наблюдаемых инструментов и `ЗарегистрироватьОбратныйВызов` (спецификация Metrics API):

- callback должен быть реентерабельным: SDK вызывает callback-и для каждого `MetricReader` отдельно,
  в том числе параллельно из разных потоков;
- callback не должен выполняться неограниченное время — без сетевых вызовов, ожидания блокировок
  и тяжёлого ввода-вывода, иначе сбор метрик задерживается;
- callback-и не должны делать дублирующие наблюдения (несколько измерений с одинаковыми атрибутами)
  по всем callback-ам инструмента — собственным и мульти-callback-ам;
- исключение callback перехватывается SDK и пишется в лог, сбор по остальным callback-ам продолжается.

## Пример

```bsl
Метр = Провайдер.ПолучитьМетр("мой-сервис", "1.0.0");

// Синхронные инструменты
Счетчик = Метр.СоздатьСчетчик("http.requests.total", "Всего HTTP-запросов", "{запросов}");
Гистограмма = Метр.СоздатьГистограмму("http.request.duration", "Длительность запроса", "s");
Датчик = Метр.СоздатьДатчик("system.memory.usage", "Использование памяти", "By");

// Наблюдаемый инструмент с callback
ОбратныйВызов = Новый Действие(ЭтотОбъект, "МойCallback");
НаблюдаемыйДатчик = Метр.СоздатьНаблюдаемыйДатчик(
    "queue.size", ОбратныйВызов, "Размер очереди", "{элементов}");
```
