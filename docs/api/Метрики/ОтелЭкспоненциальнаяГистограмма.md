# ОтелЭкспоненциальнаяГистограмма

Экспоненциальная гистограмма (ExponentialHistogram) — инструмент для распределения с логарифмическими бакетами.

## Описание

`ОтелЭкспоненциальнаяГистограмма` — расширение SDK: в спецификации OpenTelemetry такого вида
инструмента нет, экспоненциальная гистограмма там — агрегация гистограммы (Base2 Exponential Bucket
Histogram). Этот инструмент — гистограмма, у которой агрегация по умолчанию экспоненциальная: в отличие
от [ОтелГистограмма](./ОтелГистограмма.md), она использует логарифмические бакеты с автоматически
вычисляемыми границами. Вид инструмента — `ExponentialHistogram`: селектор View с типом `Histogram` его
не выбирает.
Все методы безопасны для конкурентного вызова из нескольких потоков.

Не требует предварительной настройки границ бакетов — автоматически адаптируется к диапазону значений.

Thin facade — логика в `ОтелАгрегаторЭкспоненциальнойГистограммы` и `ОтелБазовыйСинхронныйИнструмент`.

## Методы

`Записать` и `Вид` определены в самом классе, остальные методы унаследованы от
`ОтелБазовыйСинхронныйИнструмент`.

### Записать

Записывает значение в экспоненциальную гистограмму.

| Параметр | Тип | По умолчанию | Описание |
|---|---|---|---|
| `Значение` | `Число` | — | Измеренное значение |
| `Атрибуты` | `ОтелАтрибуты` | `Неопределено` | Атрибуты точки данных |
| `Контекст` | `Соответствие`, `Неопределено` | `Неопределено` | Явный контекст |

---

### Включен

Проверяет, включён ли инструмент — записывает ли он измерения (спецификация Metrics API, раздел
Enabled). У выключенного инструмента `Записать` ничего не записывает, поэтому по результату можно
не вычислять атрибуты и значение измерения.

Возвращает `Ложь`, если:

- инструмент отключён закрытием провайдера: `Закрыть()` [провайдера](./ОтелПровайдерМетрик.md)
  отключает инструменты его метров, в том числе созданные после закрытия;
- инструмент создан no-op метром: его выдаёт закрытый провайдер и no-op провайдер, пока SDK не настроен;
- все потоки инструмента используют агрегацию Drop ([`ОтелАгрегация.Отбросить()`](./ОтелАгрегация.md#отбросить)):
  её задаёт [View](./ОтелПредставление.md). Агрегацию читателя по умолчанию этот инструмент не
  использует: экспоненциальную агрегацию задаёт он сам.

Иначе возвращает `Истина`.

Вызывайте `Включен` перед каждой записью измерения и не кэшируйте результат: он может измениться во
время работы, например после регистрации View или закрытия провайдера.

| Параметр | Тип | По умолчанию | Описание |
|---|---|---|---|
| `Атрибуты` | `ОтелАтрибуты`, `Неопределено` | `Неопределено` | Зарезервирован для будущих версий, на результат не влияет |

**Возвращает:** `Булево` — `Истина`, если инструмент записывает измерения

---

### Вид

Возвращает вид инструмента.

**Возвращает:** `Строка` — `"ExponentialHistogram"`

---

### Имя

Возвращает имя инструмента. Если имя уже было зарегистрировано в метре в другом регистре, возвращается
имя первой регистрации. View с `НовоеИмя` меняет имя метрики в экспорте, а не имя инструмента.

**Возвращает:** `Строка`

---

### Описание

Возвращает описание, с которым создан инструмент.

**Возвращает:** `Строка` — пустая строка, если описание не задано

---

### ЕдиницаИзмерения

Возвращает единицу измерения, с которой создан инструмент.

**Возвращает:** `Строка` — пустая строка, если единица не задана

## Внутренние методы

Экспортированы только для вызова из других модулей SDK (в OneScript нет внутренней видимости),
приложению вызывать их не нужно:

- `СобратьДляЧитателя` — собирает потоки инструмента для читателя (вызывает `ОтелМетр.СобратьДляЧитателя`);
- `Отключить` — отключает инструмент: измерения больше не записываются, `Включен` возвращает `Ложь`
  (метр вызывает его при закрытии провайдера);
- `Хранилища`, `УстановитьХранилища` — возвращают и заменяют хранилища потоков инструмента (поток на
  читателя и View): метр задаёт их при создании инструмента и после изменения View или читателей;
- `Дескриптор`, `УстановитьДескриптор` — дескриптор инструмента (имя, вид, единица, advisory-параметры),
  по которому метр разрешает потоки;
- `УстановитьМетрВключен` — передаёт инструменту общий с метром флаг включённости (метр — при создании
  инструмента).

Остальные экспортные методы SDK не вызывает, их используют тесты; приложению они не нужны:

- `Собрать` — возвращает данные первого потока инструмента, не начиная новый интервал сбора;
- `ОчиститьТочкиДанных` — завершает интервал сбора всех потоков: при дельта-временности начинает новый
  интервал, при кумулятивной сбрасывает exemplars;
- `КоличествоСерий` — возвращает количество серий атрибутов первого потока;
- `УстановитьЛимитМощности` — задаёт лимит мощности всех потоков (потокам метра его задают View, читатель
  или сам метр);
- `УстановитьФильтрЭкземпляров` — задаёт фильтр exemplars всех потоков (потокам метра его задаёт провайдер);
- `УстановитьФабрикуРезервуаров` — задаёт фабрику резервуаров exemplars всех потоков;
- `УстановитьРезервуарЭкземпляров` — устаревший вариант: один резервуар exemplars на все серии потока,
  пишет предупреждение в лог;
- `УстановитьРазрешенныеКлючиАтрибутов`, `УстановитьИсключенныеКлючиАтрибутов` — задают фильтр ключей
  атрибутов всех потоков (потокам метра его задаёт View).

## Пример

```bsl
ДлительностьЗапроса = Метр.СоздатьЭкспоненциальнуюГистограмму(
    "http.request.duration", "Длительность HTTP-запроса", "s");

ДлительностьЗапроса.Записать(0.123);

// Дорогие атрибуты вычисляются, только если гистограмма включена.
// Включен вызывается перед каждой записью: результат может измениться
Если ДлительностьЗапроса.Включен() Тогда
    ДлительностьЗапроса.Записать(0.123, ВычислитьАтрибутыЗапроса());
КонецЕсли;
```
