# ОтелФабрикаNoopРезервуаров

Фабрика пустых резервуаров exemplars: отключает exemplars потоков представления.

## Описание

Фабрику передают в параметр `РезервуарЭкземпляров` [представления](./ОтелПредставление.md). SDK вызывает
`СоздатьРезервуар()` для каждой серии потока и получает пустой резервуар (`ОтелНоопРезервуарЭкземпляров`):
он игнорирует предложенные измерения и ничего не собирает, поэтому у точек данных потока нет exemplars.

Так отключают exemplars отдельных инструментов. Например, атрибуты, которые представление убрало из потока
(`РазрешенныеКлючиАтрибутов`, `ИсключенныеКлючиАтрибутов`), иначе попадают в exemplars как
`filteredAttributes`. Фильтр `ОтелФильтрЭкземпляров.ВсегдаВыключен()`
([ОтелФильтрЭкземпляров](./ОтелФильтрЭкземпляров.md)) отключает exemplars всех потоков провайдера
(резервуары тогда не создаются вовсе), а эта фабрика — только потоков представления.

По умолчанию SDK эту фабрику не выбирает: у агрегации `drop` резервуаров нет, а остальные агрегации получают
простые или выровненные по бакетам резервуары (см. раздел
[Резервуар по умолчанию](./ОтелФабрикаПростыхРезервуаров.md#резервуар-по-умолчанию)).

## Конструктор

```bsl
Новый ОтелФабрикаNoopРезервуаров()
```

Без параметров.

## Методы

### СоздатьРезервуар

Создаёт новый пустой резервуар.

**Возвращает:** `ОтелНоопРезервуарЭкземпляров` — резервуар, который не хранит exemplars

## Пример

```bsl
// Атрибут user.id убран из потока; чтобы он не попал в exemplars как filteredAttributes,
// exemplars потока отключены
Исключенные = Новый Массив();
Исключенные.Добавить("user.id");

Представление = Новый ОтелПредставление(, , , , ,
    Исключенные,                          // ИсключенныеКлючиАтрибутов
    Новый ОтелФабрикаNoopРезервуаров());  // РезервуарЭкземпляров

Провайдер = Новый ОтелПостроительПровайдераМетрик()
    .ЗарегистрироватьЧитатель(Читатель)
    .ЗарегистрироватьПредставление(Новый ОтелСелекторИнструментов("http.server.requests"), Представление)
    .Построить();
```
