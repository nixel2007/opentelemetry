# ОтелТипМетрики

Модуль констант типов метрик.

## Описание

`ОтелТипМетрики` — глобальный модуль с константами строковых идентификаторов типов
инструментов метрик. Используется при настройке представлений, экспорте и фильтрации.

## Функции

### Сумма

Возвращает строковый идентификатор типа Sum.

**Возвращает:** `Строка` — `"sum"`

---

### Датчик

Возвращает строковый идентификатор типа Gauge.

**Возвращает:** `Строка` — `"gauge"`

---

### Гистограмма

Возвращает строковый идентификатор типа Histogram.

**Возвращает:** `Строка` — `"histogram"`

---

### ЭкспоненциальнаяГистограмма

Возвращает строковый идентификатор типа ExponentialHistogram.

**Возвращает:** `Строка` — `"exponentialHistogram"`

---

### Сводка

Возвращает строковый идентификатор типа Summary. Инструменты SDK сводки не создают: их передают
продюсеры метрик (MetricProducer), например мосты к другим библиотекам метрик. Точка данных сводки —
`Соответствие` с ключами `attributes`, `startTimeUnixNano`, `timeUnixNano`, `count`, `sum` и
`quantileValues` (массив соответствий с ключами `quantile` и `value`). OTLP-экспортёр передаёт
сводки как `summary`, Prometheus-читатель — как Prometheus summary.

**Возвращает:** `Строка` — `"summary"`

## Пример

```bsl
// Использование при создании представления для гистограмм
Если ТипМетрики = ОтелТипМетрики.Гистограмма() Тогда
    // Применить специальные настройки агрегации для гистограмм
    Представление = Новый ОтелПредставление(
        Неопределено, Неопределено, Неопределено, Неопределено,
        СтандартныеГраницы);
КонецЕсли;
```
