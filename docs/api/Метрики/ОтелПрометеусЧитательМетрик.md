# ОтелПрометеусЧитательМетрик

Prometheus-читатель метрик — экспортирует метрики в формате Prometheus text.

## Описание

`ОтелПрометеусЧитательМетрик` реализует pull-модель сбора метрик для Prometheus.
Метрики собираются по запросу и возвращаются в формате [Prometheus text exposition](https://prometheus.io/docs/instrumenting/exposition_formats/).

Всегда использует кумулятивную временную агрегацию (`Cumulative`).

### Имена метрик

Перевод имён OTel в имена Prometheus выполняется только в этом читателе: имена и единицы
инструментов, а также OTLP-экспорт не меняются. По спецификации
[Prometheus and OpenMetrics Compatibility](https://opentelemetry.io/docs/specs/otel/compatibility/prometheus_and_openmetrics/):

- недопустимые символы имени заменяются на `_`: `http.server.requests` → `http_server_requests`;
- единица UCUM переводится в слово Prometheus и добавляется суффиксом перед суффиксом типа:
  `s` → `_seconds`, `By` → `_bytes`, `%` → `_percent` (полная таблица — в спецификации);
- части единицы в фигурных скобках отбрасываются (`{request}` суффикса не даёт),
  скорость `X/Y` становится `X_per_Y` (`By/s` → `_bytes_per_second`), безразмерная `1` суффикса не даёт;
- суффикс не добавляется, если имя уже оканчивается на эту единицу;
- к монотонной сумме (Counter) добавляется `_total`, если имя им ещё не оканчивается.
  Строки `# HELP` и `# TYPE` счётчика в text format 0.0.4 относятся к имени сэмпла: `# TYPE http_requests_total counter`.

| Инструмент OTel | Имя сэмпла Prometheus |
|---|---|
| Гистограмма `http.server.request.duration`, `s` | `http_server_request_duration_seconds_bucket` / `_sum` / `_count` |
| Счётчик `net.io`, `By` | `net_io_bytes_total` |
| Счётчик `http.requests`, `{request}` | `http_requests_total` |
| Датчик `cpu.utilization`, `1` | `cpu_utilization` |

Стратегия трансляции (`translation_strategy`) задаётся параметром конструктора:

| Стратегия | Суффиксы единиц и `_total` |
|---|---|
| `UnderscoreEscapingWithSuffixes` (по умолчанию) | добавляются |
| `NoUTF8EscapingWithSuffixes` | добавляются |
| `UnderscoreEscapingWithoutSuffixes` | не добавляются |
| `NoTranslation` | не добавляются |

Text format 0.0.4 требует экранирования символов имени в `_`, поэтому при любой стратегии имена
экранируются. Неизвестное значение стратегии логируется, используется стратегия по умолчанию.

Одноимённые метрики объединяются в одно семейство. Метрика с другим TYPE пропускается целиком.
Точка отбрасывается, если сэмпл с тем же именем и набором лейблов уже есть в выдаче, в том числе
в другом семействе. Например, так бывает у метрик `a.b` и `a_b` одной области или у счётчика `foo`
с единицей `By` (сэмпл `foo_bytes_total`) и датчика `foo_bytes_total`. В обоих случаях в лог пишется
предупреждение.

### Лейблы атрибутов

Атрибуты точек становятся лейблами (спецификация, раздел Metric Attributes):

- в имени лейбла символы вне `[a-zA-Z0-9_]`, включая `:`, заменяются на `_`: `http:method` → `http_method`;
- строковое значение выводится как есть, остальные — в JSON: `true`/`false`, `2.5`, `["x","y"]`;
- если ключи совпали после замены символов (`a.b` и `a_b`), значения склеиваются через `;`
  в порядке исходных ключей: `a_b="first;second"`.

### Лейблы области

На каждый сэмпл добавляются лейблы области инструментирования (спецификация, раздел Instrumentation Scope):

| Лейбл | Значение |
|---|---|
| `otel_scope_name` | имя области |
| `otel_scope_version` | версия области |
| `otel_scope_schema_url` | адрес схемы области |
| `otel_scope_<атрибут>` | атрибуты области, имя лейбла нормализуется как у атрибутов точек |

Пустые имя, версия и адрес схемы лейбла не дают. Атрибут области, который после префикса совпадает
с `otel_scope_name`, `otel_scope_version` или `otel_scope_schema_url`, отбрасывается. Поэтому серии
метров с одинаковыми именем и версией, но разными адресами схемы или атрибутами не склеиваются.

## Конструктор

| Параметр | Тип | По умолчанию | Описание |
|---|---|---|---|
| `Стратегия` | `Строка` | `"UnderscoreEscapingWithSuffixes"` | Стратегия трансляции имён |

Создаётся через [ОтелПостроительПровайдераМетрик](./ОтелПостроительПровайдераМетрик.md).

## Методы

### ДобавитьМетр

Регистрирует метр в читателе.

| Параметр | Тип | По умолчанию | Описание |
|---|---|---|---|
| `Метр` | `ОтелМетр` | — | Метр для регистрации |

---

### СобратьВТексте

Собирает все метрики и возвращает их в формате Prometheus text.

**Возвращает:** `Строка` — метрики в формате Prometheus text exposition

---

### ContentType

Возвращает MIME-тип ответа для HTTP-endpoint.

**Возвращает:** `Строка` — `"text/plain; version=0.0.4; charset=utf-8"`

---

### ПолучитьВременнуюАгрегацию

Возвращает тип временной агрегации для инструмента.

Всегда возвращает `Кумулятивная` независимо от типа инструмента.

| Параметр | Тип | По умолчанию | Описание |
|---|---|---|---|
| `ТипИнструмента` | `Строка` | — | Тип инструмента |

**Возвращает:** [`ОтелВременнаяАгрегация.Кумулятивная()`](./ОтелВременнаяАгрегация.md)

---

### СобратьСемейства

Собирает все метрики как семейства метрик Prometheus.

**Возвращает:** `Массив` — массив семейств метрик Prometheus

---

### СтратегияТрансляции

Возвращает стратегию трансляции имён OTel в имена Prometheus.

**Возвращает:** `Строка` — одно из значений `translation_strategy`

---

### ЛимитМощности

Возвращает лимит мощности (cardinality limit) читателя. Провайдер применяет настройки первого
зарегистрированного читателя к создаваемым метрам.

**Возвращает:** `Число` — `2000` (значение по умолчанию из спецификации)

---

### АгрегацияГистограммПоУмолчанию

Возвращает агрегацию гистограмм по умолчанию для этого читателя.

**Возвращает:** `Строка` — `"explicit_bucket_histogram"`

## Пример

```bsl
// Настройка Prometheus-читателя
ПрометеусЧитатель = Новый ОтелПрометеусЧитательМетрик();

Построитель = Новый ОтелПостроительПровайдераМетрик();
Построитель.ЗарегистрироватьЧитатель(ПрометеусЧитатель);
Провайдер = Построитель.Построить();

// В HTTP-обработчике /metrics:
// ContentType заголовок
ТипКонтента = ПрометеусЧитатель.ContentType(); 
// => "text/plain; version=0.0.4; charset=utf-8"

// Тело ответа
ТелоОтвета = ПрометеусЧитатель.СобратьВТексте();
```
