# ОтелРегистрацияНаблюдателя

Токен регистрации наблюдателя — позволяет отменить регистрацию callback.

## Описание

`ОтелРегистрацияНаблюдателя` связывает асинхронный инструмент с зарегистрированным у него callback.
Позволяет впоследствии отменить регистрацию callback вызовом `Закрыть()`.
`ДобавитьCallback` токен не возвращает, объект создаётся конструктором.

## Конструктор

| Параметр | Тип | Описание |
|---|---|---|
| `Инструмент` | `ОтелБазовыйНаблюдаемыйИнструмент` | Инструмент, у которого зарегистрирован callback |
| `Действие` | `Действие` | Зарегистрированный callback |

## Методы

### Закрыть

Отменяет регистрацию callback у инструмента. После вызова callback больше не будет вызываться
при сборе метрик.

Эквивалентно вызову `Инструмент.УдалитьCallback(Действие)`.

**Возвращает:** `Неопределено`

## Пример

```bsl
// Регистрация callback
Callback = Новый Действие(ЭтотОбъект, "МойCallback");
НаблюдаемыйСчетчик.ДобавитьCallback(Callback);
Регистрация = Новый ОтелРегистрацияНаблюдателя(НаблюдаемыйСчетчик, Callback);

// ... некоторое время работы ...

// Отменить callback (например, при завершении работы модуля)
Регистрация.Закрыть();
```
