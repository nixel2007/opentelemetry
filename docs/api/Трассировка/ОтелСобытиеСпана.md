# ОтелСобытиеСпана

Событие (Event) спана.

## Описание

Именованное событие с меткой времени и атрибутами, добавляемое к спану. Аналог Java SDK: `EventData`. Создаётся внутри SDK методом `ДобавитьСобытие` спана; доступен через `Спан.События()`.

Метка времени — строка с числом наносекунд от начала эпохи Unix, как у [спана](./ОтелСпан.md).

## Конструктор

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `Имя` | `Строка` | — | Имя события |
| `НовыеАтрибуты` | `ОтелАтрибуты` | `Неопределено` | Атрибуты события |
| `МеткаВремени` | `Строка` | `Неопределено` | Время события в наносекундах от начала эпохи Unix; по умолчанию текущее время |
| `МаксАтрибутов` | `Число`, `Неопределено` | `Неопределено` | Максимальное количество атрибутов (`Неопределено` — без ограничения, `0` — атрибуты отбрасываются) |

## Методы

### Имя

Возвращает имя события.

**Возвращает:** `Строка`

---

### Время

Возвращает метку времени события.

**Возвращает:** `Строка` — наносекунды от начала эпохи Unix

---

### Атрибуты

Возвращает атрибуты события.

**Возвращает:** `ОтелАтрибуты`

---

### КоличествоОтброшенныхАтрибутов

Возвращает количество атрибутов, отброшенных из-за лимита.

**Возвращает:** `Число`

---

### ВСоответствиеOtlp

Сериализует событие в соответствие для OTLP-экспорта.

**Возвращает:** `Соответствие` — словарь в формате OTLP

## Пример

```bsl
// Чтение событий спана
Для Каждого Событие Из Спан.События() Цикл
    Сообщить("Событие: " + Событие.Имя() + " @ " + Событие.Время());
КонецЦикла;
```
