# ОтелРезультатСэмплирования

Результат сэмплирования (SamplingResult): решение сэмплера, атрибуты и TraceState для нового спана.

## Описание

Результат возвращает [ОтелСэмплер.ДолженСэмплировать](./ОтелСэмплер.md#долженсэмплировать).
Трассировщик получает его при создании каждого спана: по решению спан записывается и экспортируется,
только записывается или отбрасывается. Непустой TraceState результата становится состоянием трассировки
нового спана.

Встроенные стратегии `ОтелСэмплер` атрибутов не возвращают, а TraceState родителя возвращают без
изменений.

## Методы

### Решение

Возвращает решение сэмплера.

**Возвращает:** `Число` — `ОтелСэмплер.РешениеОтбросить()` (`0`), `ОтелСэмплер.РешениеЗаписать()` (`1`)
или `ОтелСэмплер.РешениеЗаписатьИЭкспортировать()` (`2`)

---

### Атрибуты

Возвращает атрибуты сэмплера.

**Возвращает:** [`ОтелАтрибуты`](../Ядро/ОтелАтрибуты.md) — у встроенных стратегий пустой набор

---

### СостояниеТрассировки

Возвращает TraceState для нового спана.

**Возвращает:** [`ОтелСостояниеТрассировки`](./ОтелСостояниеТрассировки.md) — TraceState родителя;
пустое состояние, если родительского TraceState нет

## Пример

```bsl
// Проверить решение стратегии "10% трассировок" для конкретного trace ID
Результат = ОтелСэмплер.ДолженСэмплировать(
    ОтелСэмплер.ПоДолеТрассировок(), 0.1, "4bf92f3577b34da6a3ce929d0e0e4736");

Если Результат.Решение() = ОтелСэмплер.РешениеЗаписатьИЭкспортировать() Тогда
    Сообщить("Трассировка попадёт в выборку");
КонецЕсли;
```
