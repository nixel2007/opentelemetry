# ОтелНезаписывающийСпан

Незаписывающий спан (NonRecordingSpan).

## Описание

Служебный класс библиотеки. Реализует интерфейс спана, как [ОтелСпан](./ОтелСпан.md), но ничего не
записывает и не экспортирует. Такой спан возвращают:

- методы трассировщика `НачатьСпан`, `НачатьКорневойСпан`, `НачатьДочернийСпан` и
  `ОтелПостроительСпана.НачатьСпан`, если сэмплер отбросил спан или SDK не сконфигурирован;
- `ОтелСпаны.Обернуть(КонтекстСпана)` — обёртка контекста спана, например извлечённого пропагатором
  из заголовков;
- `ОтелСпаны.Невалидный()` — спан с невалидным контекстом (нулевые ID).

> **Важно:** класс предназначен только для служебного использования и НЕ должен создаваться напрямую
> через `Новый ОтелНезаписывающийСпан(...)`. Конструктор публичен только потому, что OneScript не
> поддерживает внутренние классы. Чтобы обернуть контекст спана в спан, используйте
> `ОтелСпаны.Обернуть`.

## Поведение

- `КонтекстСпана()` возвращает обёрнутый контекст спана.
- `ЗаписьАктивна()` возвращает `Ложь`.
- Остальные методы ничего не делают. Завершать такой спан не нужно.
