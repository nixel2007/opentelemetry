# ОтелПостроительПровайдераТрассировки

Построитель провайдера трассировки (SdkTracerProviderBuilder).

## Описание

Fluent API для создания [ОтелПровайдерТрассировки](./ОтелПровайдерТрассировки.md). Аналог Java SDK: `SdkTracerProvider.builder()`.

## Методы

### УстановитьРесурс

Устанавливает ресурс.

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `Значение` | `ОтелРесурс` | — | Ресурс |

**Возвращает:** `ОтелПостроительПровайдераТрассировки` — `ЭтотОбъект` для fluent API

---

### ДобавитьПроцессор

Добавляет процессор спанов. Аналог Java SDK: `SdkTracerProviderBuilder.addSpanProcessor(processor)`.

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `Процессор` | Процессор спанов | — | Встроенный ([простой](./ОтелПростойПроцессорСпанов.md), [пакетный](./ОтелПакетныйПроцессорСпанов.md), [композитный](./ОтелКомпозитныйПроцессорСпанов.md)) или свой процессор, см. [ИнтерфейсПроцессорСпанов](./ИнтерфейсПроцессорСпанов.md) |

**Возвращает:** `ОтелПостроительПровайдераТрассировки` — `ЭтотОбъект` для fluent API

---

### УстановитьСэмплер

Устанавливает сэмплер спанов. Без вызова провайдер использует сэмплер по умолчанию
`ParentBased(root=AlwaysOn)`; повторный вызов заменяет сэмплер. Аналог Java SDK:
`SdkTracerProviderBuilder.setSampler(sampler)`.

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `НовыйСэмплер` | [`ИнтерфейсСэмплер`](./ИнтерфейсСэмплер.md) | — | Встроенный сэмплер из [ОтелСэмплер](./ОтелСэмплер.md) или свой |

**Возвращает:** `ОтелПостроительПровайдераТрассировки` — `ЭтотОбъект` для fluent API

---

### УстановитьЛимитыСпана

Устанавливает лимиты спана. Аналог Java SDK: `SdkTracerProviderBuilder.setSpanLimits(spanLimits)`.

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `Значение` | `ОтелЛимитыСпана` | — | Лимиты спана |

**Возвращает:** `ОтелПостроительПровайдераТрассировки` — `ЭтотОбъект` для fluent API

---

### УстановитьГенераторИд

Устанавливает генератор идентификаторов. Генератор должен реализовывать методы `СгенерироватьИдТрассировки()` → `Строка` (32 hex) и `СгенерироватьИдСпана()` → `Строка` (16 hex). Идентификаторы — строчные hex-строки, как их передает W3C `traceparent`. Некорректный идентификатор (не hex, верхний регистр, неверная длина, одни нули) логируется как ошибка и заменяется идентификатором генератора по умолчанию; создание спана не прерывается.

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `Значение` | `Произвольный` | — | Объект-генератор идентификаторов |

**Возвращает:** `ОтелПостроительПровайдераТрассировки` — `ЭтотОбъект` для fluent API

---

### Построить

Создает экземпляр провайдера трассировки.

**Возвращает:** `ОтелПровайдерТрассировки`

## Пример

```bsl
Провайдер = Новый ОтелПостроительПровайдераТрассировки()
    .УстановитьРесурс(Ресурс)
    .ДобавитьПроцессор(Процессор)
    .УстановитьСэмплер(ОтелСэмплер.НаОсновеРодителя(ОтелСэмплер.ПоДолеТрассировок(0.25)))
    .Построить();
```
