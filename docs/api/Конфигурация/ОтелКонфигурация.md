# ОтелКонфигурация

Модель файла конфигурации: объекты с настройками SDK, которые заполняет разбор файла и читает фабрика.

## Описание

`ОтелКонфигурация` — корень модели файла конфигурации. Её поля хранят секции файла: ресурс, лимиты
атрибутов, пропагатор и провайдеры сигналов. Каждая секция — объект своего класса
`ОтелКонфигурация...`, все классы описаны в разделе «Поля». У классов модели есть только поля
(экспортные переменные), методов нет.

Модель создаёт [ОтелФайловаяКонфигурация.Разобрать](./ОтелФайловаяКонфигурация.md): читает файл,
подставляет переменные окружения `${...}`, проверяет `file_format` и заполняет поля по ключам файла.
Читает модель [ОтелКонфигурационнаяФабрика](./ОтелКонфигурационнаяФабрика.md): `Создать(Модель)`
строит по ней SDK, а `СоздатьРесурс`, `СоздатьПровайдерТрассировки`, `СоздатьПровайдерЛогирования`,
`СоздатьПровайдерМетрик` и `СоздатьПропагаторы` принимают её части: `Модель.Ресурс`,
`Модель.ПровайдерТрассировки`, `Модель.ЛимитыАтрибутов` и другие. Что фабрика строит по каждой
секции, описано на её странице; здесь — поля модели, ключи файла и значения по умолчанию.

Как `Разобрать` заполняет поля:

- ключ есть в файле — поле получает его значение, приведённое к типу поля. Если значение числового
  ключа не число (например, подстановка `${...}` дала строку `abc`), `Разобрать` выбрасывает
  исключение;
- ключа нет — поле сохраняет значение по умолчанию (колонка «По умолчанию» в таблицах);
- поле секции (тип `ОтелКонфигурация...`) равно `Неопределено`, если секции нет в файле. Ключ с
  пустым значением (например, `tracer_provider:` без вложенных ключей) тоже считается отсутствующим.
  Чтобы задать секцию со значениями по умолчанию, укажите пустой объект: `tracer_provider: {}`.
  Исключение — `otlp_http:`: схема допускает для него `null`, поэтому ключ без значения задаёт
  экспортер с настройками по умолчанию;
- поля-массивы (`Атрибуты`, `Составной`, `Процессоры`, `Читатели`, `Заголовки`) не бывают
  `Неопределено`: без ключа в файле это пустой массив. `Процессоры` и `Читатели` — массивы объектов
  модели;
- процессор не `batch` и читатель не `periodic` в массивы не попадают, экспортер не `otlp_http`
  оставляет поле `Экспортер` равным `Неопределено`; об этом разбор пишет предупреждение в лог.
  Другие ключи, которых нет в таблицах (например, `meter_provider.views`), разбор пропускает без
  предупреждения.

Модель можно изменить в коде перед вызовом фабрики: фабрика читает поля в момент вызова и ничего не
запоминает. Так можно, например, заменить адрес экспортера или сэмплер после разбора файла (см.
«Пример»). Изменения модели после `Создать` построенный SDK не меняют.
`ОтелАвтоконфигурация.Инициализировать()` по переменной `OTEL_CONFIG_FILE` вызывает `Разобрать` и
`Создать` сама и модель не возвращает. Чтобы изменить модель, вызовите обе функции в своём коде и
зарегистрируйте SDK через `ОтелГлобальный.Установить`.

Объекты модели можно создать и без файла, через `Новый` (см. «Конструктор»). Фабрика не проверяет
`ФорматФайла`. Пустая модель `Новый ОтелКонфигурация()` даёт SDK с no-op провайдерами сигналов и
[ОтелНоопПропагатор](../Пропагация/ОтелНоопПропагатор.md) — как файл с одним ключом `file_format`.

Ключи файла и поля модели:

```yaml
file_format: "1.0"                    # ФорматФайла
disabled: false                       # Отключен
resource:                             # Ресурс
  attributes:                         #   Атрибуты
    - name: service.name
      value: мой-сервис
  attributes_list: env=prod           #   СписокАтрибутов
  schema_url: https://opentelemetry.io/schemas/1.26.0  #   АдресСхемы
attribute_limits:                     # ЛимитыАтрибутов
  attribute_count_limit: 64           #   МаксКоличествоАтрибутов
propagator:                           # Пропагатор
  composite:                          #   Составной
    - tracecontext:
    - baggage:
tracer_provider:                      # ПровайдерТрассировки
  processors:                         #   Процессоры
    - batch:
        schedule_delay: 5000          #     ЗадержкаОтправки
        exporter:
          otlp_http:                  #     Экспортер
            endpoint: http://localhost:4318/v1/traces   # Адрес
  limits:                             #   Лимиты
    event_count_limit: 64             #     МаксСобытий
  sampler:                            #   Сэмплер
    parent_based:                     #     Тип
      root:                           #     Корневой
        trace_id_ratio_based:         #       Тип
          ratio: 0.1                  #       Доля
meter_provider:                       # ПровайдерМетрик
  exemplar_filter: trace_based        #   ФильтрЭкземпляров
  readers:                            #   Читатели
    - periodic:
        interval: 60000               #     Интервал
        exporter:
          otlp_http:                  #     Экспортер
            endpoint: http://localhost:4318/v1/metrics
            temporality_preference: delta
logger_provider:                      # ПровайдерЛогирования
  processors:                         #   Процессоры
    - batch:
        exporter:
          otlp_http:
            endpoint: http://localhost:4318/v1/logs
```

## Конструктор

```bsl
Новый ОтелКонфигурация()
Новый ОтелКонфигурацияРесурса()
Новый ОтелКонфигурацияЛимитовАтрибутов()
Новый ОтелКонфигурацияПропагатора()
Новый ОтелКонфигурацияПровайдераТрассировки()
Новый ОтелКонфигурацияЛимитовСпана()
Новый ОтелКонфигурацияСэмплера()
Новый ОтелКонфигурацияПровайдераМетрик()
Новый ОтелКонфигурацияПровайдераЛогирования()
Новый ОтелКонфигурацияПакетногоПроцессора()
Новый ОтелКонфигурацияПериодическогоЧитателя()
Новый ОтелКонфигурацияЭкспортераOtlpHttp()
```

Параметров у конструкторов нет: поля получают значения из колонки «По умолчанию». Это те же
значения, что получает поле при разборе файла без своего ключа. Исключение — `ЗадержкаОтправки`
пакетного процессора: при разборе секции `logger_provider` она равна 1000, у объекта из `Новый` —
5000.

## Поля

В таблицах «Ключ в файле» — ключ внутри секции, которой соответствует класс; «По умолчанию» —
значение поля у нового объекта, оно же остаётся у поля, если ключа нет в файле.

### ОтелКонфигурация

Весь файл. Объект возвращает `ОтелФайловаяКонфигурация.Разобрать`, принимает
`ОтелКонфигурационнаяФабрика.Создать`.

| Поле | Тип | По умолчанию | Ключ в файле | Описание |
|------|-----|--------------|--------------|----------|
| `ФорматФайла` | `Строка` | `""` | `file_format` | Версия формата файла. `Разобрать` требует этот ключ и принимает только версии `1.x`. Пишите версию в кавычках: `1.0` без кавычек YAML читает как число 1, и разбор выбрасывает исключение. Фабрика поле не читает |
| `Отключен` | `Булево` | `Ложь` | `disabled` | `Истина` — фабрика создаёт SDK, который не экспортирует телеметрию, и не читает остальные поля. Строковое значение (например, после подстановки `${...}`): `true` без учёта регистра — `Истина`, другое — `Ложь`; о значении, кроме `true`, `false` и пустой строки, разбор пишет предупреждение в лог |
| `Ресурс` | [`ОтелКонфигурацияРесурса`](#отелконфигурацияресурса), `Неопределено` | `Неопределено` | `resource` | Ресурс SDK; `Неопределено` — ресурс по умолчанию |
| `ЛимитыАтрибутов` | [`ОтелКонфигурацияЛимитовАтрибутов`](#отелконфигурациялимитоватрибутов), `Неопределено` | `Неопределено` | `attribute_limits` | Общие лимиты атрибутов спанов и записей логов; `Неопределено` — не заданы |
| `Пропагатор` | [`ОтелКонфигурацияПропагатора`](#отелконфигурацияпропагатора), `Неопределено` | `Неопределено` | `propagator` | Пропагаторы SDK; `Неопределено` — пропагация отключена (`ОтелНоопПропагатор`) |
| `ПровайдерТрассировки` | [`ОтелКонфигурацияПровайдераТрассировки`](#отелконфигурацияпровайдератрассировки), `Неопределено` | `Неопределено` | `tracer_provider` | Провайдер трассировки; `Неопределено` — SDK получает no-op провайдер трассировки |
| `ПровайдерМетрик` | [`ОтелКонфигурацияПровайдераМетрик`](#отелконфигурацияпровайдераметрик), `Неопределено` | `Неопределено` | `meter_provider` | Провайдер метрик; `Неопределено` — SDK получает no-op провайдер метрик |
| `ПровайдерЛогирования` | [`ОтелКонфигурацияПровайдераЛогирования`](#отелконфигурацияпровайдералогирования), `Неопределено` | `Неопределено` | `logger_provider` | Провайдер логирования; `Неопределено` — SDK получает no-op провайдер логирования |

### ОтелКонфигурацияРесурса

Секция `resource`, поле `ОтелКонфигурация.Ресурс`. Ресурс по ней создаёт
`ОтелКонфигурационнаяФабрика.СоздатьРесурс`.

| Поле | Тип | По умолчанию | Ключ в файле | Описание |
|------|-----|--------------|--------------|----------|
| `Атрибуты` | `Массив` из `Структура` | пустой массив | `attributes` | Атрибуты ресурса — структуры с полями `Имя` (`Строка`, из `name`) и `Значение` (из `value` без преобразования: строка, число, булево или массив, как прочитал YAML; без `value` — `Неопределено`). Элементы без `name` и элементы, которые не объекты, пропускаются. Ключ `type` элемента разбор не читает |
| `СписокАтрибутов` | `Строка` | `""` | `attributes_list` | Атрибуты строкой в формате `OTEL_RESOURCE_ATTRIBUTES`: `key1=value1,key2=value2`. При совпадении ключей важнее `Атрибуты` |
| `АдресСхемы` | `Строка` | `""` | `schema_url` | URL схемы ресурса; `""` — не задан |

### ОтелКонфигурацияЛимитовАтрибутов

Секции `attribute_limits` (поле `ОтелКонфигурация.ЛимитыАтрибутов`) и `logger_provider.limits`
(поле `Лимиты` [провайдера логирования](#отелконфигурацияпровайдералогирования)).

| Поле | Тип | По умолчанию | Ключ в файле | Описание |
|------|-----|--------------|--------------|----------|
| `МаксДлинаЗначенияАтрибута` | `Число`, `Неопределено` | `Неопределено` | `attribute_value_length_limit` | Максимальная длина значения атрибута; `Неопределено` — не задана |
| `МаксКоличествоАтрибутов` | `Число`, `Неопределено` | `Неопределено` | `attribute_count_limit` | Максимальное количество атрибутов; `Неопределено` — не задано |

Лимит, заданный в `limits` провайдера (`tracer_provider.limits`, `logger_provider.limits`),
перекрывает такой же лимит `attribute_limits`, как требует схема файла; лимит, не заданный в
`limits`, фабрика берёт из `attribute_limits` (см. `СоздатьПровайдерТрассировки` и
`СоздатьПровайдерЛогирования` на странице фабрики). Не заданное нигде количество атрибутов — 128,
длина значения — без ограничения.

### ОтелКонфигурацияСэмплера

Секция `tracer_provider.sampler` (поле `Сэмплер`
[провайдера трассировки](#отелконфигурацияпровайдератрассировки)) и вложенные сэмплеры
`parent_based`. В секции сэмплера один ключ — тип сэмплера, под ключом — его параметры:

```yaml
sampler:
  parent_based:
    root:
      trace_id_ratio_based:
        ratio: 0.1
    remote_parent_not_sampled:
      always_off:
```

Если значение секции не объект (например, `sampler: always_on`), разбор оставляет поле
`Неопределено`. Вложенные сэмплеры разбор заполняет только у `parent_based`.

| Поле | Тип | По умолчанию | Ключ в файле | Описание |
|------|-----|--------------|--------------|----------|
| `Тип` | `Строка` | `""` | имя ключа: `always_on`, `always_off`, `trace_id_ratio_based`, `parent_based` | Тип сэмплера. Разбор сохраняет имя ключа как есть, фабрика сравнивает его без учёта регистра; что фабрика делает с пустым и нераспознанным типом, см. `СоздатьПровайдерТрассировки` на её странице |
| `Доля` | `Число` | `1.0` | `trace_id_ratio_based.ratio` | Доля сэмплируемых трассировок, от 0 до 1; разбор заполняет её только у `trace_id_ratio_based`. У каждого сэмплера `trace_id_ratio_based`, в том числе вложенного, своя доля, см. [ОтелСэмплер](../Трассировка/ОтелСэмплер.md) |
| `Корневой` | [`ОтелКонфигурацияСэмплера`](#отелконфигурациясэмплера), `Неопределено` | `Неопределено` | `parent_based.root` | Сэмплер спанов без родителя; `Неопределено` — `always_on` |
| `УдаленныйРодительСэмплирован` | [`ОтелКонфигурацияСэмплера`](#отелконфигурациясэмплера), `Неопределено` | `Неопределено` | `parent_based.remote_parent_sampled` | Сэмплер спанов, у которых удалённый родитель сэмплирован; `Неопределено` — `always_on` |
| `УдаленныйРодительНеСэмплирован` | [`ОтелКонфигурацияСэмплера`](#отелконфигурациясэмплера), `Неопределено` | `Неопределено` | `parent_based.remote_parent_not_sampled` | Сэмплер спанов, у которых удалённый родитель не сэмплирован; `Неопределено` — `always_off` |
| `ЛокальныйРодительСэмплирован` | [`ОтелКонфигурацияСэмплера`](#отелконфигурациясэмплера), `Неопределено` | `Неопределено` | `parent_based.local_parent_sampled` | Сэмплер спанов, у которых локальный родитель сэмплирован; `Неопределено` — `always_on` |
| `ЛокальныйРодительНеСэмплирован` | [`ОтелКонфигурацияСэмплера`](#отелконфигурациясэмплера), `Неопределено` | `Неопределено` | `parent_based.local_parent_not_sampled` | Сэмплер спанов, у которых локальный родитель не сэмплирован; `Неопределено` — `always_off` |

### ОтелКонфигурацияПровайдераМетрик

Секция `meter_provider`, поле `ОтелКонфигурация.ПровайдерМетрик`. Провайдер по ней создаёт
`ОтелКонфигурационнаяФабрика.СоздатьПровайдерМетрик`.

| Поле | Тип | По умолчанию | Ключ в файле | Описание |
|------|-----|--------------|--------------|----------|
| `Читатели` | `Массив` из [`ОтелКонфигурацияПериодическогоЧитателя`](#отелконфигурацияпериодическогочитателя) | пустой массив | `readers` | Читатели метрик — по объекту на каждый элемент `- periodic:` в порядке файла |
| `ФильтрЭкземпляров` | `Строка` | `"trace_based"` | `exemplar_filter` | Фильтр exemplars: `trace_based`, `always_on` или `always_off`; фабрика сравнивает значение без учёта регистра |

### ОтелКонфигурацияПакетногоПроцессора

Элемент `- batch:` списка `processors` в секциях `tracer_provider` и `logger_provider`. Фабрика
создаёт по нему [ОтелПакетныйПроцессорСпанов](../Трассировка/ОтелПакетныйПроцессорСпанов.md) или

| Поле | Тип | По умолчанию | Ключ в файле | Описание |
|------|-----|--------------|--------------|----------|
| `ЗадержкаОтправки` | `Число` | `5000`; при разборе `logger_provider` — `1000` | `schedule_delay` | Интервал фонового экспорта, мс |
| `ТаймаутЭкспорта` | `Число` | `30000` | `export_timeout` | Таймаут экспорта, мс |
| `МаксРазмерОчереди` | `Число` | `2048` | `max_queue_size` | Максимальный размер очереди |
| `МаксРазмерПакета` | `Число` | `512` | `max_export_batch_size` | Максимальный размер пакета экспорта |
| `Экспортер` | [`ОтелКонфигурацияЭкспортераOtlpHttp`](#отелконфигурацияэкспортераotlphttp), `Неопределено` | `Неопределено` | `exporter.otlp_http` | Экспортер; `Неопределено` — в `exporter` нет `otlp_http` (например, указан `otlp_grpc` или `console`). Процессор без экспортера фабрика пропускает |

| `Экспортер` | [`ОтелКонфигурацияЭкспортераOtlpHttp`](#отелконфигурацияэкспортераotlphttp), `Неопределено` | `Неопределено` | `exporter.otlp_http` | Экспортер; `Неопределено` — в `exporter` нет `otlp_http`. ### ОтелКонфигурацияЭкспортераOtlpHttp

Ключ `exporter.otlp_http` пакетного процессора и периодического читателя. Фабрика создаёт по нему
[ОтелHttpТранспорт](../Экспорт/ОтелHttpТранспорт.md) с протоколом `http/protobuf` и экспортер
сигнала. Ключ без значения (`otlp_http:`) задаёт экспортер с настройками по умолчанию.

| Поле | Тип | По умолчанию | Ключ в файле | Описание |
|------|-----|--------------|--------------|----------|
| `Адрес` | `Строка` | `""` | `endpoint` | Полный адрес вместе с путём сигнала, например `http://localhost:4318/v1/traces`; `""` — `http://localhost:4318/v1/<сигнал>` |
| `Сжатие` | `Строка` | `""` | `compression` | `gzip` (без учёта регистра) — сжатие gzip; другое значение, в том числе `none` и `""`, — без сжатия |
| `Таймаут` | `Число` | `10000` | `timeout` | Срок каждого экспорта вместе с повторами и таймаут HTTP-запроса, мс; `0` — без ограничения |
| `Заголовки` | `Массив` из `Структура` | пустой массив | `headers` | HTTP-заголовки — структуры с полями `Имя` (из `name`) и `Значение` (строка из `value`). Элементы без `name`, без значения `value` (по схеме заголовок со значением null пропускается) и элементы, которые не объекты, пропускаются |
| `СписокЗаголовков` | `Строка` | `""` | `headers_list` | Заголовки строкой в формате `OTEL_EXPORTER_OTLP_HEADERS`: `key1=value1,key2=value2`. При совпадении имён действует значение из `Заголовки` |
| `ПредпочтениеВременнойАгрегации` | `Строка` | `""` | `temporality_preference` | Временная агрегация метрик: `cumulative`, `delta` или `low_memory` (без учёта регистра); `""` и другое значение — `cumulative` |
| `АгрегацияГистограммПоУмолчанию` | `Строка` | `""` | `default_histogram_aggregation` | Агрегация гистограмм по умолчанию: `explicit_bucket_histogram` или `base2_exponential_bucket_histogram`; `""` — `explicit_bucket_histogram` |

Поля `ПредпочтениеВременнойАгрегации` и `АгрегацияГистограммПоУмолчанию` фабрика читает только у
экспортера периодического читателя. У экспортера пакетного процессора разбор заполняет их, если
ключи есть в файле, но фабрика их не читает.

## Пример

```bsl
#Использовать opentelemetry

Модель = ОтелФайловаяКонфигурация.Разобрать("/etc/otel/config.yaml");

// Секции tracer_provider может не быть в файле
Если Модель.ПровайдерТрассировки = Неопределено Тогда
    Модель.ПровайдерТрассировки = Новый ОтелКонфигурацияПровайдераТрассировки();
КонецЕсли;
Провайдер = Модель.ПровайдерТрассировки;

// Другой адрес у экспортеров всех процессоров спанов
Для Каждого Процессор Из Провайдер.Процессоры Цикл
    Если Процессор.Экспортер <> Неопределено Тогда
        Процессор.Экспортер.Адрес = "http://collector:4318/v1/traces";
    КонецЕсли;
КонецЦикла;

// Сэмплер parent_based: 10% новых трассировок
Корневой = Новый ОтелКонфигурацияСэмплера();
Корневой.Тип = "trace_id_ratio_based";
Корневой.Доля = 0.1;
Сэмплер = Новый ОтелКонфигурацияСэмплера();
Сэмплер.Тип = "parent_based";
Сэмплер.Корневой = Корневой;
Провайдер.Сэмплер = Сэмплер;

// Фабрика читает поля модели в момент вызова
Сдк = ОтелКонфигурационнаяФабрика.Создать(Модель);
ОтелГлобальный.Установить(Сдк);
// ...
Сдк.Закрыть();
```

```bsl
// Модель без файла: спаны отправляются по OTLP/HTTP, пропагаторы W3C
Экспортер = Новый ОтелКонфигурацияЭкспортераOtlpHttp();
Экспортер.Адрес = "http://collector:4318/v1/traces";

Процессор = Новый ОтелКонфигурацияПакетногоПроцессора();
Процессор.Экспортер = Экспортер;

Модель = Новый ОтелКонфигурация();
Модель.Ресурс = Новый ОтелКонфигурацияРесурса();
Модель.Ресурс.Атрибуты.Добавить(Новый Структура("Имя, Значение", "service.name", "мой-сервис"));
Модель.ПровайдерТрассировки = Новый ОтелКонфигурацияПровайдераТрассировки();
Модель.ПровайдерТрассировки.Процессоры.Добавить(Процессор);
Модель.Пропагатор = Новый ОтелКонфигурацияПропагатора();
Модель.Пропагатор.СписокСоставного = "tracecontext,baggage";

// Секций meter_provider и logger_provider нет: у SDK только провайдер трассировки
Сдк = ОтелКонфигурационнаяФабрика.Создать(Модель);
```
