# ОтелКонфигурационнаяФабрика

Модуль создания SDK по модели файла конфигурации.

## Описание

Строит [ОтелSdk](../Ядро/ОтелSdk.md) по модели `ОтелКонфигурация`, которую возвращает
[ОтелФайловаяКонфигурация.Разобрать](./ОтелФайловаяКонфигурация.md). Аналог Java SDK:
`OpenTelemetryConfigurationFactory`. `ОтелАвтоконфигурация.Инициализировать()`, вызванная без
менеджера параметров при заданной переменной `OTEL_CONFIG_FILE`, создаёт SDK функцией `Создать` и
регистрирует его в [ОтелГлобальный](../Ядро/ОтелГлобальный.md); сама фабрика SDK глобально не
регистрирует.

Что строит `Создать` по секциям файла:

- `disabled: true` — SDK, который не экспортирует телеметрию, остальные секции не читаются: провайдер
  трассировки с сэмплером `ВсегдаВыключен` (спаны не записываются), провайдеры логирования и метрик
  без процессоров и читателей, ресурс с атрибутами по умолчанию (как `СоздатьРесурс()` без секции
  `resource`). Пропагаторы не задаются: `Сдк.Пропагаторы()` возвращает `Неопределено`;
- `resource` — ресурс, общий для всех провайдеров (см. `СоздатьРесурс`);
- `tracer_provider`, `logger_provider`, `meter_provider` — провайдеры сигналов
  (`СоздатьПровайдерТрассировки`, `СоздатьПровайдерЛогирования`, `СоздатьПровайдерМетрик`).
  Провайдер создаётся, только если секция есть в файле. Без секции у SDK нет провайдера этого
  сигнала: `Сдк.ПровайдерТрассировки()` и другие возвращают `Неопределено`. Если такой SDK
  зарегистрирован в `ОтелГлобальный`, функции `ОтелГлобальный` для этого сигнала возвращают no-op
  провайдер (когда провайдер не установлен в `ОтелГлобальный` явно);
- `attribute_limits` — общие лимиты атрибутов спанов и записей логов; как они сочетаются с `limits`
  провайдера, см. `СоздатьПровайдерТрассировки` и `СоздатьПровайдерЛогирования`;
- `propagator` — пропагаторы SDK (см. `СоздатьПропагаторы`); без секции —
  [ОтелНоопПропагатор](../Пропагация/ОтелНоопПропагатор.md).

Экспортеры процессоров и читателей отправляют данные по OTLP/HTTP: для каждого экспортера
`otlp_http` фабрика создаёт [ОтелHttpТранспорт](../Экспорт/ОтелHttpТранспорт.md) с протоколом
`http/protobuf`. Адрес `endpoint` используется как есть, включая путь (по умолчанию
`http://localhost:4318/v1/<сигнал>`); `compression: gzip` включает сжатие; `timeout` — таймаут
HTTP-запроса в миллисекундах (по умолчанию 10000); заголовки берутся из `headers` и `headers_list`,
при совпадении имён действует `headers`, как требует схема файла. Транспорт создан фабрикой, поэтому экспортер
закрывает его вместе с собой: `Сдк.Закрыть()` закрывает провайдеры, их процессоры и читатели,
экспортеры и транспорты. Пакетные процессоры и периодические читатели запускают фоновый экспорт
сразу при создании. Таймаут `Сдк.Закрыть()` без параметра — 30000 мс.

Функции `СоздатьРесурс`, `СоздатьПровайдерТрассировки`, `СоздатьПровайдерЛогирования`,
`СоздатьПровайдерМетрик` и `СоздатьПропагаторы` строят по одной части SDK из части модели.
Признак `disabled` учитывает только `Создать`.

## Функции

### Создать

Создаёт SDK по модели файла конфигурации (см. «Описание»). Если в секции `propagator` значение
`none` указано вместе с другими пропагаторами, выбрасывает исключение.

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `Модель` | [`ОтелКонфигурация`](./ОтелКонфигурация.md) | — | Модель файла конфигурации из `ОтелФайловаяКонфигурация.Разобрать` |

**Возвращает:** `ОтелSdk` — настроенный SDK; глобально не зарегистрирован

---

### СоздатьРесурс

Создаёт ресурс по секции `resource`. Основа — ресурс с атрибутами по умолчанию (`service.name` =
`unknown_service:oscript`, `telemetry.sdk.*`, атрибуты детекторов хоста, процесса и процессора).
Переменные `OTEL_SERVICE_NAME` и `OTEL_RESOURCE_ATTRIBUTES` не читаются: при файловой конфигурации
их значения попадают в ресурс только через подстановку `${...}` в файле. Поверх основы применяются:

1. `attributes_list` — строка в формате `OTEL_RESOURCE_ATTRIBUTES` (`key1=value1,key2=value2`,
   percent-encoding). Если её не удалось разобрать (элемент не в формате `ключ=значение`, пустой
   ключ, некорректный percent-encoding), значение отбрасывается целиком, ошибка пишется в лог;
2. `attributes` — список атрибутов; он важнее `attributes_list` при совпадении ключей.

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `КонфигРесурса` | [`ОтелКонфигурацияРесурса`](./ОтелКонфигурация.md#отелконфигурацияресурса), `Неопределено` | `Неопределено` | Секция `resource` (`Модель.Ресурс`); `Неопределено` — ресурс по умолчанию |

**Возвращает:** `ОтелРесурс` — ресурс

---

### СоздатьПровайдерТрассировки

Создаёт [ОтелПровайдерТрассировки](../Трассировка/ОтелПровайдерТрассировки.md) по секции
`tracer_provider`:

- процессоры — для каждого `batch` с экспортером
  [ОтелПакетныйПроцессорСпанов](../Трассировка/ОтелПакетныйПроцессорСпанов.md) с параметрами
  `schedule_delay`, `export_timeout`, `max_queue_size`, `max_export_batch_size`; процессор без
  экспортера пропускается, несколько процессоров объединяются в
  [ОтелКомпозитныйПроцессорСпанов](../Трассировка/ОтелКомпозитныйПроцессорСпанов.md);
- сэмплер — `always_on`, `always_off`, `trace_id_ratio_based` (доля `ratio`) или `parent_based` с
  корневым сэмплером `root` (по умолчанию `always_on`) и сэмплерами для родителей
  `remote_parent_sampled`, `remote_parent_not_sampled`, `local_parent_sampled`,
  `local_parent_not_sampled` (незаданные — по умолчанию
  `ОтелСэмплер.СоздатьКонфигурациюНаОсновеРодителя`, см. [ОтелСэмплер](../Трассировка/ОтелСэмплер.md)).
  Без сэмплера — `parent_based` с корневым `always_on`; нераспознанный
  тип записывается в лог предупреждением и заменяется тем же значением по умолчанию (во вложенных
  сэмплерах — `always_on`);
- лимиты спана — из `limits` провайдера. Количество атрибутов — из `limits`, если секция есть,
  иначе из `attribute_limits`, иначе 128; длина значения атрибута — из `limits`, если задана, иначе
  из `attribute_limits`, иначе без ограничения.

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `Ресурс` | [ОтелРесурс](../Ядро/ОтелРесурс.md) | — | Ресурс провайдера |
| `КонфигПровайдера` | [`ОтелКонфигурацияПровайдераТрассировки`](./ОтелКонфигурация.md#отелконфигурацияпровайдератрассировки) | — | Секция `tracer_provider` (`Модель.ПровайдерТрассировки`) |
| `КонфигГлобЛимитов` | [`ОтелКонфигурацияЛимитовАтрибутов`](./ОтелКонфигурация.md#отелконфигурациялимитоватрибутов), `Неопределено` | `Неопределено` | Секция `attribute_limits` (`Модель.ЛимитыАтрибутов`) |

**Возвращает:** `ОтелПровайдерТрассировки` — провайдер трассировки

---

### СоздатьПровайдерЛогирования

Создаёт [ОтелПровайдерЛогирования](../Логирование/ОтелПровайдерЛогирования.md) по секции
`logger_provider`. Процессоры — для каждого `batch` с экспортером
[ОтелПакетныйПроцессорЛогов](../Логирование/ОтелПакетныйПроцессорЛогов.md) (параметры те же, что у
процессора спанов); процессор без экспортера пропускается, несколько процессоров объединяются в
[ОтелКомпозитныйПроцессорЛогов](../Логирование/ОтелКомпозитныйПроцессорЛогов.md). Лимиты записей
лога: количество атрибутов — из `limits` провайдера, если секция есть, иначе из `attribute_limits`,
иначе 128; длина значения — из `limits`, если задана, иначе из `attribute_limits`, иначе без
ограничения.

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `Ресурс` | [ОтелРесурс](../Ядро/ОтелРесурс.md) | — | Ресурс провайдера |
| `КонфигПровайдера` | [`ОтелКонфигурацияПровайдераЛогирования`](./ОтелКонфигурация.md#отелконфигурацияпровайдералогирования) | — | Секция `logger_provider` (`Модель.ПровайдерЛогирования`) |
| `КонфигГлобЛимитов` | [`ОтелКонфигурацияЛимитовАтрибутов`](./ОтелКонфигурация.md#отелконфигурациялимитоватрибутов), `Неопределено` | `Неопределено` | Секция `attribute_limits` (`Модель.ЛимитыАтрибутов`) |

**Возвращает:** `ОтелПровайдерЛогирования` — провайдер логирования

### СоздатьПровайдерМетрик

Создаёт [ОтелПровайдерМетрик](../Метрики/ОтелПровайдерМетрик.md) по секции `meter_provider`:

- читатели — для каждого `periodic`
  [ОтелПериодическийЧитательМетрик](../Метрики/ОтелПериодическийЧитательМетрик.md) с интервалом
  `interval` и таймаутом экспорта `timeout`. Читателю без экспортера фабрика создаёт экспортер
  `otlp_http` с настройками по умолчанию. Временная агрегация — из `temporality_preference`
  экспортера: `delta`, `low_memory`, иначе кумулятивная; агрегацию гистограмм по умолчанию
  (`default_histogram_aggregation`, по умолчанию `explicit_bucket_histogram`) читатель берёт у
  экспортера;
- фильтр exemplars — `exemplar_filter`: `always_on`, `always_off`, любое другое значение —
  `trace_based`.

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `Ресурс` | [ОтелРесурс](../Ядро/ОтелРесурс.md) | — | Ресурс провайдера |
| `КонфигПровайдера` | [`ОтелКонфигурацияПровайдераМетрик`](./ОтелКонфигурация.md#отелконфигурацияпровайдераметрик) | — | Секция `meter_provider` (`Модель.ПровайдерМетрик`) |

**Возвращает:** `ОтелПровайдерМетрик` — провайдер метрик

---

### СоздатьПропагаторы

Создаёт пропагаторы по секции `propagator`. Имена берутся из списка `composite`, затем из строки
`composite_list` (через запятую); регистр и пробелы по краям не учитываются, повторы пропускаются.

- `tracecontext` — [ОтелW3CПропагатор](../Пропагация/ОтелW3CПропагатор.md);
- `baggage` — [ОтелW3CBaggageПропагатор](../Пропагация/ОтелW3CBaggageПропагатор.md);
- `b3`, `b3multi` — `ОтелB3Пропагатор` в формате single header или multi header. Класса нет в SDK:
  фабрика создаёт его по имени класса (`Новый("ОтелB3Пропагатор", ...)` с параметром `"single"` или
  `"multi"`), и он доступен, если установлен пакет `opentelemetry-propagator-b3` и приложение
  подключает его (`#Использовать opentelemetry-propagator-b3`). Без пакета пропагатор пропускается с
  предупреждением в логе;
- `none` — отключает пропагацию: [ОтелНоопПропагатор](../Пропагация/ОтелНоопПропагатор.md). Вместе с
  другими пропагаторами `none` указывать нельзя — функция выбрасывает исключение.

Неизвестное имя пропускается с предупреждением в логе.

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `КонфигПропагатора` | [`ОтелКонфигурацияПропагатора`](./ОтелКонфигурация.md#отелконфигурацияпропагатора), `Неопределено` | `Неопределено` | Секция `propagator` (`Модель.Пропагатор`) |

**Возвращает:** `ОтелКомпозитныйПропагатор`, `ОтелНоопПропагатор`, `Неопределено` — композитный
пропагатор из распознанных; `ОтелНоопПропагатор`, если секции нет, в ней не задано ни одного
пропагатора или задан `none`; `Неопределено`, если ни одно имя не распознано (тогда `Создать` не
задаёт пропагаторы SDK)

## Внутренние функции

Экспортированы для вызова из `ОтелАвтоконфигурация` (в OneScript нет внутренней видимости),
приложению вызывать их не нужно:

- `РазрешитьПропагаторПоИмени` — создаёт пропагатор по имени `tracecontext`, `baggage`, `b3` или
  `b3multi`; через неё пропагаторы создаёт и `ОтелАвтоконфигурация.СоздатьПропагаторы`;
- `РазобратьПарыКлючЗначение` — разбирает строку `key1=value1,key2=value2` (заголовки
  `headers_list` и `OTEL_EXPORTER_OTLP_HEADERS`): элементы без ключа пропускаются, некорректный
  percent-encoding остаётся как есть;
- `РазобратьАтрибутыРесурса` — строгий разбор `attributes_list` и `OTEL_RESOURCE_ATTRIBUTES`: при
  ошибке выбрасывает исключение.

## Пример

```bsl
#Использовать opentelemetry

Модель = ОтелФайловаяКонфигурация.Разобрать("/etc/otel/config.yaml");

// SDK по всему файлу. Фабрика не регистрирует SDK глобально
Сдк = ОтелКонфигурационнаяФабрика.Создать(Модель);
ОтелГлобальный.Установить(Сдк);

Трассировщик = ОтелГлобальный.ПолучитьТрассировщик("мой-сервис");
// ...

// При завершении работы закрываются провайдеры, процессоры, экспортеры и их транспорты
Сдк.Закрыть();
```

```bsl
// Другой вариант: только провайдер трассировки по секциям resource, tracer_provider
// и attribute_limits
Модель = ОтелФайловаяКонфигурация.Разобрать("/etc/otel/config.yaml");
Если Модель.ПровайдерТрассировки <> Неопределено Тогда
    Ресурс = ОтелКонфигурационнаяФабрика.СоздатьРесурс(Модель.Ресурс);
    Провайдер = ОтелКонфигурационнаяФабрика.СоздатьПровайдерТрассировки(
        Ресурс, Модель.ПровайдерТрассировки, Модель.ЛимитыАтрибутов);
    ОтелГлобальный.УстановитьПровайдерТрассировки(Провайдер);
    // ...
    Провайдер.Закрыть();
КонецЕсли;
```
