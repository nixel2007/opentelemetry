# ОтелТипКомпонентаКонфигурации

Модуль — перечисление типов компонентов, которые файл конфигурации создаёт через провайдеры
компонентов.

## Описание

Тип компонента передаётся в
[ОтелКонфигурационнаяФабрика.ЗарегистрироватьПровайдерКомпонента](./ОтелКонфигурационнаяФабрика.md#зарегистрироватьпровайдеркомпонента)
вместе с именем компонента. Значение — имя типа схемы конфигурации (спецификация Configuration SDK,
Supported SDK plugin components). Провайдер возвращает компонент указанного типа.

## Функции-константы

| Функция | Значение | Где в файле конфигурации | Что возвращает провайдер |
|---------|----------|--------------------------|--------------------------|
| `Пропагатор()` | `"TextMapPropagator"` | элемент `propagator.composite`, имя в `propagator.composite_list` | пропагатор с методами `Внедрить`, `Извлечь`, `Поля` |
| `ЭкспортерСпанов()` | `"SpanExporter"` | `exporter` процессора `tracer_provider.processors` | экспортер спанов |
| `ПроцессорСпанов()` | `"SpanProcessor"` | элемент `tracer_provider.processors` | процессор спанов |
| `Сэмплер()` | `"Sampler"` | `tracer_provider.sampler`, сэмплеры в `parent_based` и `always_record` | сэмплер ([ИнтерфейсСэмплер](../Трассировка/ИнтерфейсСэмплер.md)) |
| `ГенераторИд()` | `"IdGenerator"` | `tracer_provider.id_generator` | генератор с методами `СгенерироватьИдТрассировки`, `СгенерироватьИдСпана` |
| `ЧитательМетрикPull()` | `"PullMetricExporter"` | `exporter` читателя `pull` | читатель метрик, например [ОтелПрометеусЧитательМетрик](../Метрики/ОтелПрометеусЧитательМетрик.md) |
| `ЭкспортерМетрик()` | `"PushMetricExporter"` | `exporter` читателя `periodic` | экспортер метрик |
| `ПродюсерМетрик()` | `"MetricProducer"` | элемент `producers` читателя | продюсер метрик с методом `Произвести(Ресурс, ТаймаутМс)` |
| `ЭкспортерЗаписейЛога()` | `"LogRecordExporter"` | `exporter` процессора `logger_provider.processors` | экспортер записей лога |
| `ПроцессорЗаписейЛога()` | `"LogRecordProcessor"` | элемент `logger_provider.processors` | процессор записей лога |

**Возвращает:** `Строка`

## Пример

```bsl
ОтелКонфигурационнаяФабрика.ЗарегистрироватьПровайдерКомпонента(
    Новый МойПровайдерСэмплера(), ОтелТипКомпонентаКонфигурации.Сэмплер(), "my_sampler");
```
