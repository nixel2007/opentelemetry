# ОтелУтилиты

Модуль вспомогательных функций SDK: время в формате OpenTelemetry, часы и генератор идентификаторов.

## Описание

Время в API библиотеки — строка с числом наносекунд от начала эпохи Unix (1970-01-01 00:00:00 UTC),
например `"1700000000500000000"`. В этих единицах метки времени передаёт OTLP. Спецификация
допускает точность от миллисекунд до наносекунд: время, которое SDK ставит само, имеет точность до
миллисекунд (последние шесть цифр — нули), а время из внешнего источника с большей точностью
передаётся без потерь.

Своё время задают, когда событие уже произошло: время начала спана, если момент создания спана
прошёл, время окончания спана, время события спана, время записи лога. Строку для такого времени
дают функции модуля:

- текущее время — `ТекущееВремяВНаносекундах()`;
- время, засечённое через `ТекущаяУниверсальнаяДатаВМиллисекундах()`, — `МиллисекундыВНаносекунды()`.

Часы и генератор идентификаторов модуля общие для всего SDK в процессе. Генератор у конкретного
провайдера трассировки задаёт
[ОтелПостроительПровайдераТрассировки.УстановитьГенераторИд](../Трассировка/ОтелПостроительПровайдераТрассировки.md#установитьгенераторид).

## Функции

### ТекущееВремяВНаносекундах

Возвращает текущее время. Если установлены свои часы (см. `УстановитьЧасы`), время берётся из них.

**Возвращает:** `Строка` — наносекунды от начала эпохи Unix

---

### МиллисекундыВНаносекунды

Переводит время из миллисекунд от 0001-01-01 UTC — формата `ТекущаяУниверсальнаяДатаВМиллисекундах()`
и библиотеки logos — в наносекунды от начала эпохи Unix.

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `МиллисекундыОт0001` | `Число` | — | Целое число миллисекунд от 0001-01-01 UTC |

**Возвращает:** `Строка` — наносекунды от начала эпохи Unix

---

### УстановитьЧасы

Устанавливает свои часы (аналог Java SDK: `SdkTracerProviderBuilder.setClock`). Часы — объект с
функцией `ТекущееВремяВНаносекундах()`, которая возвращает строку наносекунд от начала эпохи Unix.
Часы общие для всего SDK: из них берётся всё время, которое SDK ставит само, — начало и окончание
спанов, время событий, записей логов, точек метрик и exemplars.

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `Значение` | `Произвольный` | — | Объект с функцией `ТекущееВремяВНаносекундах()` |

---

### СброситьЧасы

Возвращает системные часы.

---

### УстановитьГенераторИд

Устанавливает генератор идентификаторов для провайдеров трассировки, у которых свой генератор не
задан. Генератор — объект с функциями `СгенерироватьИдТрассировки()` (32 hex-символа) и
`СгенерироватьИдСпана()` (16 hex-символов). Идентификатор должен быть строчной hex-строкой нужной
длины не из одних нулей; некорректный идентификатор пишется в лог как ошибка и заменяется
идентификатором генератора по умолчанию (на основе `УникальныйИдентификатор`).

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `Генератор` | `Произвольный` | — | Объект с функциями `СгенерироватьИдТрассировки()` и `СгенерироватьИдСпана()` |

---

### СброситьГенераторИд

Возвращает генератор идентификаторов по умолчанию.

## Внутренние функции

Экспортированы только для вызова из других модулей SDK (в OneScript нет внутренней видимости),
приложению вызывать их не нужно:

- `СгенерироватьИдТрассировки`, `СгенерироватьИдСпана` — идентификаторы для провайдера трассировки;
- `ВШестнадцатеричнуюСтроку`, `ИзШестнадцатеричнойСтроки`, `ЯвляетсяШестнадцатеричнойСтрокой`,
  `ЯвляетсяШестнадцатеричнойСтрокойВНижнемРегистре`, `ЯвляетсяВалиднымИдентификатором` — разбор и
  проверка hex-значений для пропагаторов и сэмплера;
- `РаскодироватьURLСтрого` — разбор percent-encoding в атрибутах ресурса из окружения;
- `ЗначениеАтрибутаВФорматОтел`, `ОграничитьЗначениеАтрибута` — перевод значения атрибута в OTLP
  и лимиты длины и глубины;
- `ВерсияSDK`, `ВерсияПакета`, `UserAgentЭкспортераOtlp` — версия SDK для ресурса и User-Agent
  экспортера;
- `РесурсДетектора` — ресурс детекторов хоста, процесса и процессора.

Функции `Транслитерировать` (кириллица в латиницу в нижнем регистре) и `ПроверитьИмяМетрики`
(исключение, если имя не из символов `a-z`, `A-Z`, `0-9`, `_`, `.`, `-` или начинается не с буквы)
SDK не вызывает: имя инструмента проверяет метр по правилам спецификации.

## Пример

```bsl
// Операция уже прошла: время начала и окончания засечены заранее
Начало = ТекущаяУниверсальнаяДатаВМиллисекундах();
// ... операция ...
Окончание = ТекущаяУниверсальнаяДатаВМиллисекундах();

Спан = Трассировщик.НачатьСпан("Загрузка", , , , ОтелУтилиты.МиллисекундыВНаносекунды(Начало));
Спан.Завершить(ОтелУтилиты.МиллисекундыВНаносекунды(Окончание));
```
