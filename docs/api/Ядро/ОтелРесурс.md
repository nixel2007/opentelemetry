# ОтелРесурс

Класс описания ресурса (Resource) по спецификации OpenTelemetry.

## Описание

Ресурс описывает сущность, производящую телеметрию: сервис, хост, процесс и т.д. Ресурс с атрибутами по умолчанию (`Новый ОтелРесурс()`) содержит:

- `service.name` = `unknown_service:oscript`, `telemetry.sdk.name`, `telemetry.sdk.language`, `telemetry.sdk.version`;
- атрибуты детекторов [хоста](./ОтелДетекторРесурсаХоста.md) (`host.name`, `os.type`), [процесса](./ОтелДетекторРесурсаПроцесса.md) (`process.pid`) и [процессора](./ОтелДетекторРесурсаПроцессора.md) (`host.cpu.model.name`, `host.arch`);
- атрибуты из `OTEL_RESOURCE_ATTRIBUTES` и имя сервиса из `OTEL_SERVICE_NAME`, если не задан `БезОкружения`. Они важнее атрибутов выше, а `OTEL_SERVICE_NAME` важнее `service.name` из `OTEL_RESOURCE_ATTRIBUTES`.

Атрибуты можно дополнить через [ОтелПостроительРесурса](./ОтелПостроительРесурса.md).

## Конструктор

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `БезУмолчаний` | `Булево` | `Ложь` | Если `Истина`, не добавлять атрибуты по умолчанию |
| `АдресСхемы` | `Строка` | `""` | URL схемы ресурса. Если не задан, у ресурса с атрибутами по умолчанию — схема семантических соглашений детекторов ресурса; детектор, не определивший ни одного атрибута, схему не задаёт |
| `БезОкружения` | `Булево` | `Ложь` | Если `Истина`, атрибуты по умолчанию не дополняются из `OTEL_RESOURCE_ATTRIBUTES` и `OTEL_SERVICE_NAME` (так ресурс создаёт файловая конфигурация) |

## Методы

### Атрибуты

Возвращает атрибуты ресурса.

**Возвращает:** `ОтелАтрибуты` — атрибуты ресурса

---

### АдресСхемы

Возвращает URL схемы ресурса. OTLP-экспортёры передают непустой URL в поле `schemaUrl`
группы ресурса; ресурсы с одинаковыми атрибутами и разными схемами экспортируются отдельными
группами.

**Возвращает:** `Строка` — URL схемы или пустая строка

---

### Слить

Создает новый ресурс как результат слияния текущего с другим. Атрибуты другого ресурса имеют приоритет.

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `ДругойРесурс` | `ОтелРесурс` | — | Ресурс для слияния |

**Возвращает:** `ОтелРесурс` — новый ресурс со слитыми атрибутами

---

### ВСоответствиеOtlp

Преобразует ресурс в соответствие формата OTLP JSON.

**Возвращает:** `Соответствие` — `{"attributes": [...]}`

## Пример

```bsl
Ресурс = Новый ОтелПостроительРесурса()
    .Установить("service.name", "мой-сервис")
    .Установить("service.version", "1.0.0")
    .УстановитьАдресСхемы("https://opentelemetry.io/schemas/1.24.0")
    .Построить();

ИмяСервиса = Ресурс.Атрибуты().Получить("service.name"); // "мой-сервис"
```
