# ОтелСущность

Сущность ресурса (Entity) по спецификации OpenTelemetry, статус Development.

## Описание

Сущность — объект, с которым связана телеметрия: сервис, хост, процесс, контейнер. Она задаётся
типом, идентифицирующими атрибутами (идентичность, хотя бы один атрибут), описательными атрибутами
и адресом схемы атрибутов ([Entity Data Model](https://opentelemetry.io/docs/specs/otel/entities/data-model/)).
Сущности передаются ресурсу при создании ([ОтелРесурс](./ОтелРесурс.md), параметр
`НачальныеСущности`) или через [ОтелПостроительРесурса](./ОтелПостроительРесурса.md); их атрибуты
становятся атрибутами ресурса.

Атрибуты копируются при создании: изменение переданного соответствия сущность не меняет.

## Конструктор

| Параметр | Тип | По умолчанию | Описание |
|---|---|---|---|
| `ИмяТипа` | `Строка` | — | Тип сущности, обязательный: `service`, `host`, ... |
| `ИдентифицирующиеАтрибуты` | `Соответствие`, `Структура`, `ОтелАтрибуты` | — | Идентичность сущности, хотя бы один атрибут |
| `ОписательныеАтрибуты` | `Соответствие`, `Структура`, `ОтелАтрибуты` | `Неопределено` | Описательные атрибуты |
| `АдресСхемыАтрибутов` | `Строка` | `""` | Адрес схемы атрибутов сущности |

## Методы

### ТипСущности

**Возвращает:** `Строка` — тип сущности

---

### Идентификатор

**Возвращает:** `ФиксированноеСоответствие` — идентифицирующие атрибуты

---

### Описание

**Возвращает:** `ФиксированноеСоответствие` — описательные атрибуты

---

### АдресСхемы

**Возвращает:** `Строка` — адрес схемы атрибутов или пустая строка

---

### Атрибуты

**Возвращает:** `Соответствие` — все атрибуты сущности: идентифицирующие и описательные

---

### Валидна

**Возвращает:** `Булево` — тип не пустой и идентичность содержит хотя бы один атрибут. Ресурс
невалидные сущности пропускает с ошибкой в логе

---

### МожноСлить

Проверяет, можно ли слить сущность с другой: совпадают тип, адрес схемы и идентичность (те же
ключи с теми же значениями).

| Параметр | Тип | По умолчанию | Описание |
|---|---|---|---|
| `Другая` | `ОтелСущность` | — | Сущность |

**Возвращает:** `Булево`

---

### Слить

Возвращает новую сущность: описательные атрибуты объединены, значения другой сущности приоритетнее.
Вызывается для сливаемых сущностей (см. `МожноСлить`).

| Параметр | Тип | По умолчанию | Описание |
|---|---|---|---|
| `Другая` | `ОтелСущность` | — | Сливаемая сущность |

**Возвращает:** `ОтелСущность`

---

### СодержитАтрибут

| Параметр | Тип | По умолчанию | Описание |
|---|---|---|---|
| `Ключ` | `Строка` | — | Ключ атрибута |

**Возвращает:** `Булево` — атрибут входит в идентифицирующие или описательные атрибуты сущности

## Пример

```bsl
Хост = Новый ОтелСущность("host", Новый Структура("host.id", "H1"), Новый Структура("host.name", "web-1"));
Сервис = Новый ОтелСущность("service", Новый Структура("service.name", "checkout"));

Ресурс = Новый ОтелПостроительРесурса()
    .ДобавитьСущность(Хост)
    .ДобавитьСущность(Сервис)
    .Построить();
```
