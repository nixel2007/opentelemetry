# ОтелДетекторРесурсаХоста

Детектор ресурса хоста: имя компьютера и тип операционной системы.

## Описание

[ОтелРесурс](./ОтелРесурс.md) с атрибутами по умолчанию вызывает этот детектор вместе с
[ОтелДетекторРесурсаПроцесса](./ОтелДетекторРесурсаПроцесса.md) и
[ОтелДетекторРесурсаПроцессора](./ОтелДетекторРесурсаПроцессора.md) и добавляет найденные атрибуты в
ресурс. Самому вызывать детектор нужно, только чтобы получить эти атрибуты отдельно.

| Атрибут | Значение |
|---------|----------|
| `host.name` | Имя компьютера (`СистемнаяИнформация.ИмяКомпьютера`) |
| `os.type` | `linux`, `windows` или `darwin` (macOS); на другой платформе — тип платформы OneScript в нижнем регистре |

Если сведения получить не удалось, детектор пишет ошибку в лог `oscript.lib.opentelemetry.resource.host`
и возвращает ресурс без недоступных атрибутов. Исключение он не выбрасывает.

## Конструктор

```bsl
Новый ОтелДетекторРесурсаХоста()
```

Без параметров.

## Методы

### Обнаружить

Определяет атрибуты хоста.

**Возвращает:** [`ОтелРесурс`](./ОтелРесурс.md) — ресурс без атрибутов по умолчанию: только атрибуты
хоста и адрес схемы `https://opentelemetry.io/schemas/1.29.0`. Если ни один атрибут не определён —
пустой ресурс без адреса схемы

## Пример

```bsl
РесурсХоста = Новый ОтелДетекторРесурсаХоста().Обнаружить();
ИмяХоста = РесурсХоста.Атрибуты().Получить("host.name");
```
