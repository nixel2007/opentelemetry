# ОтелДетекторРесурсаЭкземпляраСервиса

Детектор ресурса экземпляра сервиса: идентификатор экземпляра.

## Описание

[ОтелРесурс](./ОтелРесурс.md) с атрибутами по умолчанию вызывает этот детектор и добавляет найденный
атрибут в ресурс. Самому вызывать детектор нужно, только чтобы получить этот атрибут отдельно.

| Атрибут | Значение |
|---------|----------|
| `service.instance.id` | Случайный UUID, один на процесс |

Как и в Java SDK, идентификатор создаётся один раз на процесс: все ресурсы процесса получают одно и
то же значение, а после перезапуска процесса значение новое. Значение из `OTEL_RESOURCE_ATTRIBUTES`,
`resource` файловой конфигурации или [ОтелПостроительРесурса](./ОтелПостроительРесурса.md)
заменяет сгенерированное.

## Конструктор

```bsl
Новый ОтелДетекторРесурсаЭкземпляраСервиса()
```

Без параметров.

## Методы

### Обнаружить

Определяет атрибут экземпляра сервиса.

**Возвращает:** [`ОтелРесурс`](./ОтелРесурс.md) — ресурс без атрибутов по умолчанию: только
`service.instance.id` и адрес схемы `https://opentelemetry.io/schemas/1.44.0`

## Пример

```bsl
РесурсЭкземпляра = Новый ОтелДетекторРесурсаЭкземпляраСервиса().Обнаружить();
ИдЭкземпляра = РесурсЭкземпляра.Атрибуты().Получить("service.instance.id");
```
