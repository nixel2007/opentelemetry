# ОтелДетекторРесурсаПроцессора

Детектор ресурса процессора: модель и архитектура процессора.

## Описание

[ОтелРесурс](./ОтелРесурс.md) с атрибутами по умолчанию вызывает этот детектор вместе с
[ОтелДетекторРесурсаХоста](./ОтелДетекторРесурсаХоста.md) и
[ОтелДетекторРесурсаПроцесса](./ОтелДетекторРесурсаПроцесса.md) и добавляет найденные атрибуты в
ресурс. Самому вызывать детектор нужно, только чтобы получить эти атрибуты отдельно.

Сведения о процессоре определяет библиотека cpuinfo (`ИнформацияОПроцессоре`) при каждом вызове
`Обнаружить()`, если они не переданы в конструктор. Атрибут, который cpuinfo не определил
(например, на неподдерживаемой платформе), в ресурс не попадает.

| Атрибут | Значение |
|---------|----------|
| `host.cpu.model.name` | Имя процессора |
| `host.arch` | `amd64`, `x86`, `arm64` или `arm32`; другая архитектура — её имя из cpuinfo в нижнем регистре |

Если сведения получить не удалось, детектор пишет ошибку в лог `oscript.lib.opentelemetry.resource.cpu`
и возвращает ресурс без недоступных атрибутов. Исключение он не выбрасывает.

## Конструктор

```bsl
Новый ОтелДетекторРесурсаПроцессора(СведенияОПроцессоре)
```

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `СведенияОПроцессоре` | `ИнформацияОПроцессоре` | `Неопределено` | Готовые сведения о процессоре из cpuinfo; `Неопределено` — cpuinfo определяет их при каждом вызове `Обнаружить()` |

## Методы

### Обнаружить

Определяет атрибуты процессора.

**Возвращает:** [`ОтелРесурс`](./ОтелРесурс.md) — ресурс без атрибутов по умолчанию: только атрибуты
процессора и адрес схемы `https://opentelemetry.io/schemas/1.29.0`. Если ни один атрибут не определён —
пустой ресурс без адреса схемы

## Пример

```bsl
РесурсПроцессора = Новый ОтелДетекторРесурсаПроцессора().Обнаружить();
Архитектура = РесурсПроцессора.Атрибуты().Получить("host.arch"); // например, "amd64"
```
