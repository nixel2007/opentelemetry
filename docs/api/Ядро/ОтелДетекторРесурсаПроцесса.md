# ОтелДетекторРесурсаПроцесса

Детектор ресурса процесса: идентификатор текущего процесса.

## Описание

[ОтелРесурс](./ОтелРесурс.md) с атрибутами по умолчанию вызывает этот детектор вместе с
[ОтелДетекторРесурсаХоста](./ОтелДетекторРесурсаХоста.md) и
[ОтелДетекторРесурсаПроцессора](./ОтелДетекторРесурсаПроцессора.md) и добавляет найденные атрибуты в
ресурс. Самому вызывать детектор нужно, только чтобы получить эти атрибуты отдельно.

| Атрибут | Значение |
|---------|----------|
| `process.pid` | Идентификатор процесса (`ТекущийПроцесс().Идентификатор`) |

Если идентификатор получить не удалось, детектор пишет ошибку в лог
`oscript.lib.opentelemetry.resource.process` и возвращает пустой ресурс. Исключение он не выбрасывает.

## Конструктор

```bsl
Новый ОтелДетекторРесурсаПроцесса()
```

Без параметров.

## Методы

### Обнаружить

Определяет атрибуты процесса.

**Возвращает:** [`ОтелРесурс`](./ОтелРесурс.md) — ресурс без атрибутов по умолчанию: только
`process.pid` и адрес схемы `https://opentelemetry.io/schemas/1.29.0`. Если идентификатор не
определён — пустой ресурс без адреса схемы

## Пример

```bsl
РесурсПроцесса = Новый ОтелДетекторРесурсаПроцесса().Обнаружить();
ИдПроцесса = РесурсПроцесса.Атрибуты().Получить("process.pid");
```
