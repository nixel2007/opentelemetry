# ОтелПостроительРесурса

Построитель ресурса — расширение SDK: в спецификации OpenTelemetry построителя ресурса нет.

## Описание

Fluent API для создания [ОтелРесурс](./ОтелРесурс.md) с произвольными атрибутами. Аналог Java SDK:
`io.opentelemetry.sdk.resources.ResourceBuilder`.

Новый построитель пуст, как `Resource.builder()`: ресурс получает только установленные атрибуты.
Построитель с атрибутами существующего ресурса возвращает `ОтелРесурс.ВПостроитель()`, например
`ОтелРесурсы.ПоУмолчанию().ВПостроитель()`.

## Методы

### Установить

Устанавливает атрибут ресурса.

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `Ключ` | `Строка` | — | Имя атрибута |
| `Значение` | `Произвольный` | — | Значение атрибута |

**Возвращает:** `ОтелПостроительРесурса` — `ЭтотОбъект` для fluent API

---

### УстановитьВсе

Устанавливает несколько атрибутов из `ОтелАтрибуты`.

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `Значение` | `ОтелАтрибуты` | — | Атрибуты для добавления |

**Возвращает:** `ОтелПостроительРесурса` — `ЭтотОбъект` для fluent API

---

### УстановитьАдресСхемы

Устанавливает URL схемы семантических атрибутов ресурса.

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `Значение` | `Строка` | — | URL схемы (например, `"https://opentelemetry.io/schemas/1.44.0"`) |

**Возвращает:** `ОтелПостроительРесурса` — `ЭтотОбъект` для fluent API

---

### Построить

Создает ресурс из установленных атрибутов и адреса схемы.

**Возвращает:** `ОтелРесурс` — созданный ресурс

## Пример

```bsl
Ресурс = ОтелРесурсы.ПоУмолчанию().ВПостроитель()
    .Установить("service.name", "мой-сервис")
    .Установить("service.version", "1.0.0")
    .Построить();
```
