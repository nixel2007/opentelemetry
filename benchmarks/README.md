# Бенчмарки

Замеры стоимости горячих путей SDK и экспорта OTLP на библиотеке [benchmark](https://github.com/Stivo182/BenchmarkOneScript).
Сеть не нужна: бенчмарки экспорта меряют подготовку данных OTLP и кодирование, которые выполняются в потоке экспорта
до отправки запроса.

| Файл | Что меряет |
|---|---|
| `БенчмаркЭкспортаСпанов.os` | пачка спанов: входящие HTTP-запросы и запросы к базе данных |
| `БенчмаркЭкспортаЛогов.os` | пачка записей журнала с контекстом трассировки |
| `БенчмаркЭкспортаМетрик.os` | выгрузка метрик HTTP-сервера: гистограмма, счетчик, реверсивный счетчик |
| `БенчмаркСозданияСпанов.os` | создание и завершение спана: корневой, дочерний, корневой с начальными атрибутами |
| `БенчмаркЗаписиЛогов.os` | создание записи журнала, запись с атрибутами через простой и пакетный процессор |
| `БенчмаркЗаписиМетрик.os` | запись измерения гистограммы и счетчика с атрибутами и без, ключ набора атрибутов |

Методы бенчмарков экспорта:

- `ПодготовкаOtlp` — экспортер собирает данные OTLP из объектов SDK; шаг общий для всех протоколов;
- `КодированиеHttpProtobuf` — кодирование в protobuf для `http/protobuf`;
- `КодированиеHttpJson` — сериализация в JSON для `http/json`;
- `КонвертацияGrpc` — подготовка данных для `grpc` до вызова компоненты OPI_GRPC.

Бенчмарки создания спанов, записи логов и метрик меряют путь SDK от вызова API до процессора: экспортеров нет,
пакетный процессор копит записи без фонового экспорта.

## Запуск

```bash
opm install -l
(cd benchmarks && opm install -l benchmark)
oscript benchmarks/запуск.os
```

Библиотека `benchmark` ставится в `benchmarks/oscript_modules`: ее зависимости расходятся по версиям с зависимостями
разработки библиотеки, и `benchmarks/oscript.cfg` ищет модули сначала там, потом в `oscript_modules` корня.
Бенчмарки запускает `запуск.os` через API библиотеки; командой `benchos run` они не запускаются, ее процесс
конфликтует с модулем `Сериализатор` из зависимости `oscript-yaml`.

Без аргументов запускаются все файлы `Бенчмарк*.os`. Аргументы — имена файлов и дополнительные значения параметров:

```bash
oscript benchmarks/запуск.os БенчмаркЭкспортаСпанов.os КоличествоСпанов=128
```

Замер идет и для значения параметра по умолчанию, и для заданного.
