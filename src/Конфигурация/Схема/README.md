# Схема файла конфигурации

`opentelemetry_configuration.json` — JSON Schema модели конфигурации OpenTelemetry из релиза
[opentelemetry-configuration v1.2.0](https://github.com/open-telemetry/opentelemetry-configuration/blob/v1.2.0/opentelemetry_configuration.json)
без изменений. По ней `ОтелФайловаяКонфигурация.Разобрать` проверяет файл конфигурации.

Схема распространяется по лицензии Apache License 2.0, текст лицензии — в файле [LICENSE](LICENSE).
